# 별빛 아레나 — 요정·챕터 확장

현재 규칙은 6, 시즌 표식은 2입니다. 이번 업데이트는 성장·재화·기존 클리어를 초기화하지 않습니다. 전환하지 않았던 이전 계정도 보유 성장값을 그대로 이어받습니다.

- 14개 챕터, 일반 125개 스테이지 + 기존 크리스마스 이벤트. 처음 3개 챕터는 5단계, 고대 유적부터 10단계이며 5단계 중간 보스·10단계 최종 보스입니다.
- 기존 50개 ID·입장 에너지·코인 보상은 유지합니다. 기존에 열린 챕터 접근권을 별도로 보존하고 클리어/첫 보상 기록을 만들거나 지우지 않습니다.
- 마지막 정식 입장 성공 파티는 공유 계정 JSON에 ID·순서·소유자·시각으로 저장합니다. 편성 화면 초안이나 실패 요청은 이를 덮어쓰지 않습니다. 최대 5명, 영이/찬미, COST 및 보유 여부는 서버에서 확인합니다.
- 에너지 100 상한, 6분당 1 회복, 한국시간 자정 전체 충전. 날짜 변경 이력은 기존 refresh 또는 아레나 명령의 서버 CAS에 반영하며 새 폴링/크론/유료 충전은 추가하지 않습니다. 초 단위 카운트다운은 서버 시각 오프셋을 이용한 로컬 표시입니다.
- 초회·반복 XP 및 에너지당 효율이 스테이지 순서대로 상승합니다. 규칙 6의 동료별 일일 상한은 16,000 XP입니다. 일반 육성 경험치는 변경하지 않습니다.
- 내부 beast/resonance/fusion ID·저장 필드는 유지하고 화면 명칭은 요정/속성으로 표시합니다.
- `legacy-v5` 및 이전 엔진은 진행 중 전투 재현 전용입니다. 서버는 입장 때의 규칙·레벨·성급·강화·스킬·시드·행동 로그로 보상/중복을 검증합니다.
- 실제 게임 캐릭터 원화는 덮어쓰지 않습니다. 신지역 그림만 추가했고 선택한 전투 지역 이미지와 파티 아틀라스를 로드합니다.

## 추가 아트 출처와 한계

`scripts/prepare-arena-fairy-art.mjs`에서 직접 작성한 SVG 지형·건축·몬스터 도형으로 새 4개 지역의 배경 및 4행×4프레임 몬스터 시트를 생성합니다. 배경 4개+시트 4개 원본 합계 48,831바이트입니다. 단순 팔레트 교체가 아니라 정원 식물/미궁·거울/천공 건축/성좌 제단과 각기 다른 실루엣을 그립니다. 새 몬스터 모션은 네 프레임의 작은 상하 움직임이며 풀 프레임 손그림 애니메이션이 아닙니다. 기존 챕터의 새 최종 보스는 기존 보스 시각 자료를 재사용하고 이름·전투 패턴을 구분합니다. AI 생성 원화나 새 고해상도 픽셀 원화라고 보고하지 않습니다.

이전 캐릭터·기존 지역의 승인된 이미지, PixiJS/GSAP 연출과 아틀라스는 재사용합니다. 새 게임 엔진·패키지는 추가하지 않습니다. 브라우저 검사는 Chromium 모바일 에뮬레이션이며 실기기 iOS/Android 검증과 다릅니다.
