# 별빛 아레나 본 게임 통합

- 거실 성장·모험 메뉴의 **별빛 아레나**에서 진입. `GameShell`의 기존 숨김/동결/복귀 구조를 사용한다.
- 보유 친구 5종과 친구별 실제 성장 레벨을 입장 시 복사한다. 기본 사람 이름 ‘남자아이/여자아이’는 전투에서 영이/찬미 별칭으로 표시하며 저장된 이름을 변경하지 않는다. 사용자 지정 이름은 그대로 표시한다.
- 기본 전투 레벨은 ‘친구 실제 레벨’. ‘연습 Lv.’ 선택은 현재 전투만 바꾸며 실제 육성 데이터에 쓰지 않는다.
- 연습 전투에는 코인/XP/아이템 보상이 없다. 서버 명령, 보상 수령, Supabase 쓰기, DB 마이그레이션을 추가하지 않는다. 기존 보상 검증을 변경하지 않는다.
- 1개 숲 / 5명 / 일반 몬스터 2종 / 보스 1종, COST 10, 최대 4명, 사람 1명 필수. 기존 시제품의 이미지와 모션을 재사용한다.
- UI와 CSS는 지연 로드하고 `.starlight-arena` 아래로 한정한다. 기존 거실 테마와 다른 미니게임 CSS를 변경하지 않는다. 압축 아트는 정적 웹사이트에서만 가져오며 Supabase Egress를 사용하지 않는다.
- `model.ts`: 순수 전투 계산. `integration.ts`: 읽기 전용 보유 친구 어댑터. `Arena.tsx`: 편성/전투. `Battle.ts`: Pixi 렌더러. `assets.ts`: Vite URL.
- 렌더러는 종료 시 ticker/listener/자체 생성 ImageSource를 정리한다. 탭 비활성화 시 ticker 정지. 기존 클라우드 큐/동기화는 GameShell의 기존 경로를 유지한다.

## 아트 출처와 한계

승인된 독립 시제품에서 이미지 생성 도구로 별도 제작한 일러스트와 전투용 픽셀 원화를 재사용했다. 원본 기존 캐릭터 PNG나 사용자 사진을 덮어쓰지 않았다. 원본 아트는 이전에 제공한 `starlight-arena-source.zip`에 보존했으며, `art/metadata.json`에 원본 해시·압축 크기·아틀라스 정보를 기록했다. 메타데이터의 `source`/`output`는 시제품 아카이브 안의 경로이고, 이 저장소에서 사용하는 출력은 `src/arena/art/`에 있다.

친구는 별도 제작한 20프레임의 64×64 아틀라스이며 몬스터는 각 4프레임이다. 도트 생성 원화를 프레임 분리·투명 잔여 조각 제거·nearest 정규화했으며 일러스트 카드를 축소해 전투 캐릭터로 쓰지 않는다. 모든 방향의 긴 걷기/전환 보간이나 3D 조명을 완성한 것은 아니다. 배경 깊이는 2D 일러스트·필드·전경 레이어다.

수정 동굴/별빛 성역, 나머지 3명, 실보상/랭킹, RPG 저장·성장은 추가 구현하지 않았다. 모바일 화면/터치 검사는 Chromium 에뮬레이션이며 실기기 Android/iOS 검증과 구분한다. 사용 라이브러리는 기존 React/PixiJS이고 새 엔진/의존성은 추가하지 않았다.

운영 반영과 클릭 방법: [상세 배포·플레이 안내](../../docs/STARLIGHT_ARENA_DEPLOY_GUIDE.md).
