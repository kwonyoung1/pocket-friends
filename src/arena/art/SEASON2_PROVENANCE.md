# Season 2 adventurer art

Eight original AI-generated painted portraits and two separately generated pixel animation sheets, guided by existing Youngi/Chanmi art. Original references remain unchanged. Source paths and crop/frame mapping are recorded in scripts/prepare-arena-season2.mjs. Ten distinct drawn poses per adventurer: two idle, two walking, basic attack, skill 20, skill 35, hurt, victory, down. Twenty runtime slots reuse these poses; motion is interpolated by existing PixiJS. These are not twenty hand-drawn unique frames. Original generated PNG sources remain in /workspace/generated_images and optimized runtime WebP/PNG are versioned. No commercial game assets used. The guild concept mentioned in the request was not attached; actual repository protagonists served as reference.
