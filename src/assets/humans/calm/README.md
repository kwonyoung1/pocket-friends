# Human stroll atlas

The accepted gait is a lightly lively indoor stroll with readable arm swing,
not the discarded tiny-step draft. Folder name `calm` denotes the removal of
exaggerated bouncing, not a motionless final gait.

Each person has eight 512px review WebP frames and a 2048×256 runtime strip.
Character/HumanSprite uses the strip only for movement; existing idle, expression,
sleep and personal photo paths remain. No existing original PNG is replaced.
