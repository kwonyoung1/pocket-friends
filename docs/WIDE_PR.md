## 변경 내용

상점 구매를 수량 선택/총액 확인 방식으로 바꾸고, 여러 재고를 서버에서 한 번에 검증·판매하는 일괄 거래를 추가합니다. 가격·잔액·보유 수량을 서버에서 다시 계산하며, 잘못된 판매 항목은 전체를 취소합니다. 기존 작업 ID와 PostgreSQL 원자적 커밋으로 동시 입력과 응답 유실 후 재시도에서 중복 차감/지급을 방지합니다.

별도 오답 복습 게임은 제거하고 기존 기록은 비활성 데이터로 보존합니다. 오답 목록의 개별/선택 삭제, 전체 삭제 추가 확인, 정상 탐험의 직접 정답 시 자동 삭제와 출제 시 최대20% 오답 혼합을 추가합니다. 원래90개를 보존하고 검토한 고유 단어300개(난이도별100개)를 추가해 총390개입니다. **목표 신규1000개/난이도는 아직 미달이며,900개씩 총2700개가 후속 검수 범위**입니다.

방의 두 축과 이동/충돌 좌표를 sqrt(1.5)배로 확장하고 카메라 내부 스크롤을 제공합니다. 캐릭터 좌표상 크기·속도는 유지하며 가구·햄스터·친구 위치는 한 번만 변환합니다. 새 SQL은 첫 변환 직전 월드를 비공개 테이블에 트랜잭션으로 백업합니다. 기존 사진·친구·육성·코인·아이템·탐험·인증을 보존합니다.
