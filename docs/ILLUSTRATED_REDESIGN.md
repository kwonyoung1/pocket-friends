# 캐릭터 원화·방 리디자인 실제 구현 보고

## 참고자료와 제작 방식

`01_room_style_reference.png`, `02_character_expression_reference.png`, `03_room_ui_reference.png`는 접근 가능한 작업 폴더에서 찾지 못했습니다. 따라서 시안과의 정확한 일치도를 검수하지 않았습니다. 기존 `boy.png`, `girl.png`를 직접 확인하고 갈색 머리, 남자의 회색 니트, 여자의 앞머리·긴 머리·검은 재킷, 청바지·흰 운동화라는 기존 특징을 기준으로 새 SD 벡터 원화를 그렸습니다.

이번 변경은 기존 그림에 CSS 색만 바꾸는 작업이 아닙니다. 아래 7개의 새 SVG를 실제 `Character`와 `HumanSprite` 렌더링 경로에 연결했습니다. 원본 한 장에 없는 자세를 추출했다고 주장하지 않습니다. 사람의 서기·앉기·이불 수면은 새로 그린 도형이고 걷기는 분리한 새 팔·다리 레이어 애니메이션입니다. 원본 PNG는 저장소에 남겼습니다.

## 실제 렌더링 경로

- `src/Character.tsx`: **등록 사진이 있으면 먼저 그대로 표시**합니다. 사진이 없는 동물만 새 SVG로 표시합니다. 사람은 `HumanSprite`로 전달합니다.
- `src/humans/HumanSprite.tsx`: 기존 한 장 PNG 대신 새 사람 SVG와 확정된 기존 포즈 상태를 연결합니다.
- `src/art/IllustratedSprite.tsx`: 프로젝트에 포함된 신뢰 가능한 SVG만 사용합니다. 사용자가 업로드한 문자열을 SVG 마크업으로 삽입하지 않습니다. 인스턴스별 ID로 그라데이션/머리 심볼 충돌을 방지합니다.
- `src/art/styles.css`: 표정·독립 눈/귀/꼬리/팔/다리·수면 레이어 전환을 담당합니다.
- `src/cozy/LivingMotion.tsx`: 화면에 보이는 유휴 친구에게만 불규칙한 깜빡임·갸웃·주변 보기·하품 등을 분산합니다. 게임 난수와 분리된 기존 `visualRandom`을 사용합니다.

표정은 기본 눈, 미소 눈, 감은 눈, 놀란 눈, 기쁜 입, 작은 입, 놀란/배고픈 입을 실제 도형으로 전환합니다. 머리 전체를 비균일하게 늘이는 호흡·앉기 효과는 제거하고 몸통/이불만 미세하게 호흡하도록 했습니다. 시선은 근처 친구나 현재 경로 방향에서 읽은 값을 사용하며 이동 좌표를 쓰거나 보상을 만들지 않습니다.

## 사람의 8가지 상태

|상태|구현 방식|
|---|---|
|기본 서기|새 서 있는 몸·바지·신발 도형|
|웃음|별도 눈·입 도형 전환|
|활짝 기쁨|활짝 웃는 입·눈, 들어 올린 팔, 작은 점프|
|졸림|감은 눈·하품과 기존 낮은 체력 상태 연동|
|놀람|큰 눈·O형 입|
|걷기|새 서 있는 다리·팔을 독립적으로 교차 움직임; 기존 이동 방향의 좌우 반전 사용|
|앉기|별도로 그린 접힌 청바지·신발 레이어 표시|
|잠자기|새 베개·이불·누운 몸 도형과 재사용 머리 레이어; 얼굴은 균일 축소/회전만 사용|

**미구현/대체:** 별도로 그린 측면·후면 원화, 프레임별 수작업 보행 시트, 실제 옆얼굴을 새로 그린 수면 프레임은 없습니다. 걷기는 정면 SD 인형의 관절식 보행이고 수면은 새 이불 도형과 정면 머리를 조합한 표현입니다. 첨부 시안이 없으므로 시안 인물의 얼굴까지 동일하게 재현했다고 주장하지 않습니다.

## 새 방과 인터페이스

`src/Room.tsx`의 실제 SVG를 다시 그렸습니다. 넓은 아치 창문, 직물 커튼, 따뜻한 우드 바닥, 스티치/직조 러그, 쿠션과 담요가 있는 소파, 원목 아치 책장, 벽 쪽 캣타워, 꽃과 식물, 컵과 책이 놓인 테이블을 독립 그룹으로 렌더링합니다. 방 시안 이미지를 배경으로 합성하지 않았습니다.

기존 고정 가구 영역과 바닥 좌표를 유지하고, 새 캣타워는 이동 바닥 밖의 장식입니다. 신규 구매 아이템이나 충돌 장애물을 만들지 않습니다. `RoomExtras`의 사용자 배치 가구·보물은 별도의 기존 데이터 레이어로 남아 회수·이동·중첩 기능을 그대로 사용합니다.

화면에는 실제 친구들의 사진/원화·이름·레벨에 연결된 **거실 친구 선택 바**를 새로 추가했습니다. 메인 메뉴는 PC의 한 줄 배치/모바일 3열, 초상은 큰 액자형, 게이지는 두꺼운 숫자+막대 카드, 돌보기는 큰 아이콘 카드로 정리했습니다. 새 재화를 만들지 않고 코인·친밀도 등 기존 값만 표시합니다. ‘모두 먹이주기/모두 씻기/모두 놀아주기’와 기존 확인 절차는 유지합니다.

## 실제 돌보기 반응

`src/art/activity.ts`는 기존 사용 성공 메시지와 현재 `eatingUntil/furnitureUntil`이 동시에 유효할 때만 실제 사용 아이템을 표시합니다. 실패/쿨타임 메시지에는 새 성공 연출을 만들지 않습니다.

- 음식: 실제 음식 아이콘 전달·아래 시선·입 움직임, 좋아하는 음식의 기존 행복 반응 유지
- 작은 공: 공 아이콘·꼬리/팔 반응
- 인형: 인형 아이콘·느린 귀/팔 반응
- 특별 장난감: 기존 아이콘·팔과 반짝임 반응
- 씻기: 기존 목욕 상태·거품, 감은 눈; 완료 후 기존 회복 반짝임 유지
- 쉬기/수면: 별도 앉은/누운 도형, 조용한 호흡과 Zzz

서버의 수치·물건 소모·재사용·6시간 쓰다듬기 보상·목욕 제한을 변경하지 않습니다.

## 성능과 검증

새 거실/캐릭터에 PixiJS 앱이나 GSAP를 추가하지 않았습니다. SVG는 인스턴스 ID와 정적 마크업을 메모하고, 눈·몸·팔다리는 CSS/작은 타이머로 표시합니다. 화면 밖/백그라운드/감소 모션에서는 장식 실행을 멈춥니다. 실제 모바일 GPU의 장시간 FPS/발열을 측정했다고 주장하지 않습니다.

검증 범위는 캐릭터·방·드래그·돌보기·사진·핵심 저장/동기화에 한정했습니다. 관련 없는 사천성·보물 3매치 전체 테스트는 반복하지 않았습니다.

- 관련 단위 테스트83개 통과: 사람 포즈 우선순위, 읽기 전용 활동 표시, 기존 일괄 관리·가구 배치/이동·저장 마이그레이션 등
- 관련 PC/모바일 검사36개 통과 후, 얼굴/시선/호흡 보강에 관련된 최종18개 재검증 통과
- 새 SVG7종의 투명 여백·비어 있지 않은 원화·명암 색상·ID 중복 없음 확인
- 인간의 실제 서기/앉기/수면 레이어와 감소 모션 확인
- 핵심 두 기기 클라우드 검사6개 통과: 구매 재시도, 사람 친구/이름/사진/친밀도, 음식·휴식 동기화
- 개인 사진 크롭·저장·재접속 및 같은 사진에서 서로 다른 영역 추출 검사4개 통과. 최종 TypeScript 검사·프로덕션 빌드 및 번들 분리 검사도 통과했습니다.

`src/game.ts`, 서버/SQL, 상태 계산, 보상, 장비, 탐험, 미니게임, 가구 좌표/충돌 계산은 수정하지 않습니다. 저장 데이터 마이그레이션은 필요하지 않습니다. 영단어 미니게임을 복구하지 않았습니다.
