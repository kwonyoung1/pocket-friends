# 직접 조작과 교감

기존 v1 저장 키와 포맷을 유지하며, 기존 사진·상태·추억·유효한 위치를 그대로 읽습니다. `petRewardAfter`, `lastPetLine`만 선택적인 저장 항목으로 추가했습니다. 포인터 ID, 누르기 상태, 표정 등 일시적인 상태는 읽어 들이지 않아 다시 접속했을 때 잡힌 채 남지 않습니다.

## 입력 상태

| 입력 | 전이 | 보상 |
| --- | --- | --- |
| 누름 | pressing: 걷기 중단, 경로 초기화 | 없음 |
| 0.8초 미만에 뗌 | delighted: 짧은 쓰다듬기 | 일반 1회, 쿨타임 검사 |
| 0.8초 유지 | petting: 눈 감기, 작은 하트, 손길에 집중 | 없음 |
| 2초 유지 | bonding: 여러 하트, 특별 대사 | 특별 1회, 쿨타임 검사 |
| 이동 거리 기준 초과 | dragging: 진행 중인 쓰다듬기 취소 | 없음 |
| 드래그 놓기 | landing → settling → idle | 없음 |
| 교감 후 놓기 | settling → idle | 추가 지급 없음 |
| 취소·포커스 이탈 | settling → idle | 추가 지급 없음 |

전이는 `interaction.ts`에 있고, 시간과 보상은 `balance.ts`에서 조정합니다. 동일한 누름에서 `rewardAttempted`를 한 번만 소비합니다. 2초 유지 보상이 이미 지급된 뒤 드래그로 바뀌어도 추가 지급하지 않습니다. 쿨타임 중 시작한 특별 교감은 보상 시도가 끝난 것으로 처리하므로, 손을 계속 대고 기다려 쿨타임이 끝나도 다시 지급하지 않습니다.

누르기 판정은 CSS 픽셀 거리, 배치는 방의 1000×640 좌표를 사용해 반응형 화면에서도 같은 공간을 유지합니다. 목표를 유효한 바닥으로 투영하고 지수 보간으로 따라갑니다. 착지 뒤 경로에 다시 합류할 때에도 첫 경로 구간이 가구 모서리를 가로지르지 않도록 검사합니다. 손을 놓은 다음 기본 1.5초 후 자율 이동으로 복귀합니다.

## 반응과 우선순위

`플레이어(4) > 긴급 상태(3) > 친구 대화(2) > 자동 대사(1)` 순서입니다. `speak`는 높은 우선순위의 진행 중인 말풍선을 낮은 우선순위가 덮지 못하게 합니다. 잡혀 있거나 반응 중인 친구는 자율 이동과 일반/긴급/친구 대화를 중단합니다. 나머지 친구는 계속 활동합니다.

일반 대사는 친밀도 세 구간별 목록에서 고르며 직전 대사를 제외합니다. 특별 대사는 공통 목록에 친구별 말투와 친밀도별 어미를 붙입니다. `affinity`와 `reactionLinesByAffinity`를 내보내므로 추후 근접 인사 같은 새로운 트리거에도 같은 친밀도 구분을 적용할 수 있습니다. 현재 커서 접근만으로 인사하는 기능은 구현하지 않습니다.

`headByFriend`의 `normal`/`photo`는 이미지 상단부터의 상대 높이 기준입니다. 예를 들어 `photo: 0.5`는 이미지 위쪽 절반을 머리 영역으로 봅니다. 정확한 해부학적 인식이 아닌 사용자 조정 가능한 영역입니다. 기본 캐릭터의 SVG에는 normal/smile/closed 눈 표현이 있으며, 사진에는 눈이나 얼굴 변형을 적용하지 않고 전체 이미지의 이동·회전과 주변 효과만 사용합니다. 동작 줄이기 설정에서는 반복 흔들림과 떠오르는 모션을 없애고 정적인 하트를 표시합니다.

## 입력 취소와 접근성

캐릭터별 Pointer Events와 포인터 캡처로 마우스·펜·터치를 통합합니다. 각 친구는 자기 포인터만 처리하고 다른 친구와 동시에 조작할 수 있습니다. pointercancel, lostpointercapture, 창 blur/pagehide, 문서 숨김, 창 밖 포인터 이탈, resize, Esc에서 세션을 정리합니다. 캡처가 유지되는 동안 방 밖으로 이동했다가 페이지 안에서 놓아도 종료됩니다.

터치 기본 동작은 캐릭터 버튼에서만 제한합니다. 클릭은 pointerup에서 확정하고 키보드/보조 기술의 click만 별도로 처리해 중복 실행을 막습니다. 별도 친구 카드에서 쓰다듬지 않고 상태를 선택할 수 있습니다.

## 테스트

- 단위 테스트: 단계 전이, 드래그 전환, 취소, 한 번의 보상, 공유 쿨타임, 값 범위, 개별 포인터, 사진 영역, 대사 중복 방지, 우선순위, 위치 투영, 경로 복귀, 저장 호환성.
- 브라우저: PC/모바일 화면에서 실제 마우스와 Chromium 네이티브 터치 입력, 눈/하트/말풍선, 드래그·착지·재이동, 포커스/캡처 취소, 기존 사진과 쿨타임 복원.
- 실제 iOS Safari와 물리 기기의 펜 입력은 별도 검증이 필요합니다.
