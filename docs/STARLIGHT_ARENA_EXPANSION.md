# 별빛 아레나 확장 구현·검증 기록

## 실제 캐릭터 연동

`characters.ts`는 ID로 전투 설정을 조회하고, `integration.ts`는 실제 보유 Friend의 이름·종류·레벨을 연결합니다. 보유하지 않은 입양 친구를 지급하지 않습니다. 실제 카탈로그에 없는 ‘나비’를 추가하지 않았습니다. 향후 새 ID는 명시 설정 또는 종류별 기본 전투 설정으로 연결할 수 있습니다. 햄스터 장식은 성장 데이터가 있는 Friend가 아니므로 출전 목록에 포함하지 않습니다.

## 지역·전투

달빛 숲 / 안개 호수 / 수정 동굴 / 고대 유적 / 불꽃 협곡 / 얼어붙은 설원 / 그림자 숲 / 별빛 성역: 각 5개, 총 40개. 각 지역 일반 2종·정예 1종·보스 1종, 총 32종입니다. 보스는 숲의 수호자·안개의 이무기·수정 거신·고대 수호자·협곡의 불꽃왕·오로라 사슴·밤의 늑대·월광 비스트입니다.

지역별 5가지 배치, 치유·결계·상태 이상·광역·체력 절반 이하 보스 패턴을 적용했습니다. 이전 클리어로 다음 단계가 열리고 재도전 가능합니다. 6속성, 약점 게이지·브레이크, 독·화상·빙결·기절, 강화·약화, 정화, 도발·반격, 행동 순서 지원, 3종 역할·탱커/힐러·화염/두두 시너지가 실제 계산에 반영됩니다. 상태는 동일 종류 중첩 1개·최대 3턴이며 행동 불능 후 공통 내성으로 영구 봉쇄를 막습니다.

참고 방향: 스타레일의 약점과 행동 선택, 에픽세븐의 역할·상태·조합, 옥토패스의 브레이크·다단 공략을 작은 모바일 전투에 맞게 선정했습니다. 원본 UI·캐릭터·상업용 자산은 복제하지 않았습니다. 이번 환경에서는 세 게임의 공식 사이트 접속이 프록시 403으로 거부돼 최신 공식 자료·실제 플레이를 직접 확인했다는 주장은 하지 않습니다.

## 저장·보상·트래픽

기존 `game_worlds.data` JSON에 선택적 `world.arena`만 추가합니다. DB 스키마·RLS·사용자 계정·기존 재화 필드는 초기화하지 않습니다. 기존 CAS 커밋과 명령 영수증을 재사용합니다. 서버가 보유 친구·실제 레벨로 티켓과 시드를 생성하고, 액티브 해금·별빛·대상·턴을 모든 행동 재생으로 검증합니다. 승리·레벨·코인 수량을 클라이언트 입력으로 받지 않습니다. 임의 백업으로 서버 아레나 기록을 주입하는 것도 차단합니다.

정식 전투는 시작·종료와 웨이브 전환/중단 체크포인트에만 명령을 보냅니다. 타일·프레임·공격 연출마다 API를 보내지 않습니다. 로컬 행동 로그는 이어하기 보조용이며 서버 체크포인트보다 오래된 기록으로 덮어쓸 수 없습니다. 티켓 6시간·행동 160개·공유 월드 티켓 16개로 기록 크기를 제한합니다.

보상: 첫/반복 코인·경험치 구분, 첫 보스는 기존 강화석·희귀 보물 연결. 공유 월드 하루 5회·120코인·친구별 XP 100 한도, 한국 시간 초기화. 중복·동시 완료·응답 유실 후 재전송에 중복 지급하지 않습니다. Lv.50은 XP 지급 제외. 한도 이후 클리어 진행은 저장하고 미수령 첫 보상은 보상 가능일 재도전으로 받습니다. 연습은 서버 보상·진행을 변경하지 않습니다.

## 그래픽

신규 친구 5명의 독립 일러스트와 100개 픽셀 포즈, 7개 독립 지역 배경, 적 32종의 128개 포즈를 제작했습니다. PixiJS 기존 엔진과 2배속·컷인·카메라·히트 스톱을 재사용하고 그림자 잔상·서리·물결·덩굴·방패·응원 등 효과를 구분했습니다. 파티클 상한·백그라운드 정지·모션 감소·장면 정리를 유지합니다. 새 이미지 용량과 원본 SHA는 `src/arena/art/expansion-metadata.json`, 원본은 `art-source/arena-expansion/`에 있습니다. 뭉치·별이의 추가 다리 오류는 image_gen으로 교정한 원본만 반영했습니다.

## 운영 배포 상태의 판단

GitHub API와 운영 사이트 접속은 이 환경에서 프록시 403으로 차단돼 원격 CI·자동 병합·서버/웹 SHA를 직접 확인할 수 없습니다. Git 푸시와 PR 확인은 가능한 범위에서 별도로 보고합니다. 로컬 검증·코드 반영을 운영 배포 성공으로 대신 보고하지 않습니다. 기존 보호 대상 리뷰·운영 승인은 유지하며 [클릭 안내서](./STARLIGHT_ARENA_DEPLOY_GUIDE.md)로 필요한 상태를 확인합니다.
