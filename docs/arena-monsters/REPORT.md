## 그래픽

9~14장의 기존 몬스터 ID 26종과, 11~14장 중간 보스 전용 강화형 4개를 포함해 30개 외형을 연결했습니다. 지역마다 512×640 투명 WebP 1개, 128px 셀 5행×4열입니다. 합계 **1,057,118바이트(약 1.01MiB)**이며 실제 입장한 지역만 이미지로 로드합니다. 기존 원화·이전 시트는 삭제/덮어쓰기하지 않았습니다. 11~14장 배경은 이번 변경 범위가 아니며 기존 배경을 유지합니다.

제작 출처는 이미지 생성 도구입니다. 각 외형에 **대기·공격·피격 3개 실제 제작 포즈**, 총 90개 포즈를 제작하고 여백·투명 배경을 보강했습니다. Sharp 파이프라인은 알파 영역 분리, 미세 잡음 제거, 크기 정규화와 포장, WebP 품질92/알파100 변환만 수행합니다. 대기는 1px 호흡 보간을 추가하며 처치는 페이드/하강입니다. 별도의 날개 관절 애니메이션이나 손으로 그린 사망 프레임을 제작했다고 주장하지 않습니다. 그리핀은 네 다리·두 날개를 기준으로 제작/시각 검토했습니다. 원본 생성 PNG는 작업 환경의 `outputs/monster-clean`에 있고, 저장소에는 런타임 시트와 원본/결과 SHA256을 보관합니다. 재포장에는 원본 6개 PNG가 필요합니다.

9장 월식 원호·마법진, 10장 빛기둥, 11장 꽃잎·덩굴, 12장 거울 파편, 13장 바람 고리·번개, 14장 별자리 시계 연출을 구분했습니다. 정예 연격, 보스 오라/등장, 광역 필살기 배너를 연결했습니다. 기존 PixiJS를 재사용하고 파티클 제한과 모션 감소/저사양 설정을 유지했습니다.

- 일반 적: 낮은 확률의 지역 상태 이상, 단일 공격 대상 분산.
- 정예: 2회 연격, 약화된 대상 우선 공략, 상태 이상 연계.

- 대응 여유: 방어 계산 후 **적 광역 필살기 45%, 다른 광역 40%, 연격 각 타격 38%, 단일 65%**의 대상 최대 HP 상한을 적용하고 이후 보호막을 차감합니다. 이 상한은 5장 이후 일반 콘텐츠에만 적용합니다. 여러 적의 연계 공격·지속 피해는 여전히 위험하며 무적 처리가 아닙니다.

적의 일괄 약화로 고등급을 보장하지 않고, 전설 환수 기본 HP×1.6/ATK×2.4/DEF×1.4를 조정했습니다. 아스트라는 공격 시 전원 보호막(기본10%, 다른 공격18%, 기존 강화 계산 적용)을 더해 느린 포격 역할을 보완합니다. 세라피아는 HP×1.5/ATK×1.35/DEF×1.5, 지원계수2.4, 기본 공격의 약한 아군 회복20%, 성역의 재생·정화·공격 강화25%로 생존 지원을 강화합니다. 기존 저장 성급·레벨·강화값을 바꾸지 않는 계산 정의 변경입니다.

## 데이터·보안·배포

보유 기록/레벨/XP/성급/합성/마스터리/훈련/스킬/코인/상자/클리어/최초 보상/에너지/마지막 파티의 저장 구조와 값을 초기화하지 않습니다. DB 스키마와 RLS, 인증, 보상 영수증·CAS, 서버 승리 재현을 유지합니다. 운영 DB를 읽거나 수정하지 않았으므로 운영 사용자별 보존을 실측했다고 주장하지 않습니다.

현재 실행 중인 규칙6 전투는 `legacy-v6`의 전투·캐릭터·적·강화·공명 정의로 재현하며 공격 예고도 같은 엔진으로 표시합니다. 규칙1~5도 유지합니다. 기존 승리는 원래 보상표로 한 번만 정산합니다. 새 전투만 규칙7을 사용합니다. 프로필 조작/재전송/동시 정산/세션 만료의 기존 서버 검사를 유지합니다.

로컬 검사: 관련 단위/서버175개, Deno 고정 lock 검사, TypeScript/Vite 빌드 통과. 모바일 Chromium 에뮬레이션에서 클라우드 진입/정산/재접속/마지막 파티 보존4개와 6개 지역의 자산 지연 로딩·360/375/390/412px 화면·공격/피격·저사양/모션 감소 설정 검증을 수행했습니다. 실제 Android/iOS 물리 기기 검증은 수행하지 않았습니다.

GitHub API는 이 실행 환경에서 `403 Forbidden`을 반환했습니다. Git 푸시/자동 PR과 병합/운영 배포의 확인 결과는 최종 응답에서 별도로 기록합니다. 웹/서버 최신 SHA와 CI가 확인되지 않으면 운영 반영 완료로 보지 않습니다. 기존 정책상 리뷰·운영 승인은 유지하며 [클릭 안내](../ARENA_MONSTER_DEPLOY_GUIDE.md)를 따릅니다.
