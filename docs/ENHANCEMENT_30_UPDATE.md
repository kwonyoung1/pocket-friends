# 장비 +30강 · 보물 보상 개선 · 영단어 운영 종료

기준 main: `09b152d`. 브랜치: `feat/equipment-enhancement-30`.

## 게임에서 사용하는 방법

**캐릭터 성장 → 장비**, 또는 **인벤토리 → 장비**에서 개별 카드의 **강화·상세**를 누릅니다. 상세가 있는 위치로 자동 이동합니다. 비용, 기본 확률, 실패 보정, 최종 확률과 성공 후 효과를 확인한 뒤 **+N 강화 시도**를 누릅니다. 실제 강화는 Supabase 공유 월드에서만 가능합니다. 로컬 연습에서는 재화를 차감하지 않고 상세만 볼 수 있습니다.

기존20종/중복 개체 모두 개별 강화됩니다. 기존/신규 장비는 강화 필드가 없으면+0, 실패0으로 해석합니다. 실패해도 현재 단계와 장비를 유지하며 비용은 소모합니다. 성공하면 실패 횟수를0으로 초기화합니다. +30에서는 추가 시도가 불가능합니다. +10 푸른 별빛, +20 보라 마법진/번개 장식, +30 황금/무지개 링이 카드·상세·착용 슬롯에 별도 레이어로 표시됩니다. reduced-motion에서는 회전을 멈춥니다.

## 강화석과 탐험

|지역|독립 획득 확률|수량|
|---|---:|---:|
|신비의 숲 / 반짝이는 해변|0%|0|
|고대 동굴|20%|1|
|비밀의 정원|30%|1~2|
|수정 광산|40%|1~3|
|잊혀진 신전|50%|2~4|
|별빛 성역|60%|3~6|

강화석은 기존 보물·가구·추가 이벤트·장비 추첨을 끝낸 후 별도로 추첨합니다. 출발 시 수량을 확정하고 귀환 시 한 번 지급합니다. 인벤토리와 장비 화면에서 보유 수량을 확인하며 구매/판매 기능은 없습니다. 이번 업데이트 이전에 이미 출발한 탐험에 강화석을 소급 추가하지 않습니다.

강화 효과는+0/5/10/15/20/25/30에서 기본의1/1.1/1.25/1.45/1.7/2/2.5배이며 중간 단계는 선형 보간합니다. 장비 기본 효과20%는+30에서50%가 됩니다. 합산 상한은 시간 단축50%, 기본 탐험 코인 증가150%, 희귀·전설 합산 확률 증가12%p입니다. 시간 단축은 성격 보정까지 포함해 지역 기본 시간의50%보다 짧아지지 않습니다. 코인 증가는 지역 기본 코인에만 적용하며 추가 이벤트 코인/보물 판매에는 적용하지 않습니다.

공통 `bonusWeights` 함수로 화면과 서버가 같은 확률을 계산합니다. 증가분을 희귀80%/전설20%로 나누고 일반/고급의 비율을 유지해 차감합니다. 숲/해변은 전설0%를 유지하고 전설 몫도 희귀에 더합니다. 각 지역 확률 합은100%, 어느 등급도 음수가 되지 않습니다. 보물의 기존 지역 제한은 그대로입니다.

장비 효과, 착용ID/강화 단계, 최종 확률과 실제 결과를 출발 시 저장합니다. 탐험 중 강화/해제를 해도 기존 여행의 시간·아이템·코인·강화석은 다시 계산하지 않습니다.

## 영단어 운영 종료와 데이터 보존

메뉴·문제/스테이지/힌트/오답노트/쿨타임 화면과 전용 UI 컴포넌트/CSS를 제거했습니다. 서버의 모든 word 명령을 거절하고 자동 만료 처리도 중단하여 진행 중이던 기록을 종료·정산·삭제하지 않습니다. 새 영단어 코인 지급은 없습니다. 과거 지급 코인을 회수하지 않습니다.

기존 `world.words`와 데이터 파서, 타입, 과거 모델/문제 원본은 호환성·향후 복원을 위해 보관합니다. 운영 진입점에서는 이 모델과 문제집을 가져오지 않습니다. 기존 데이터를 읽고 저장해도 학습 기록을 그대로 남깁니다. 사천성/보물3매치 제품 파일과 서버 명령 분기는 그대로이며 일반 영어 대사는 변경하지 않았습니다.

## 저장/서버

기존 Supabase 프로젝트와 월드JSON을 사용하며 **새 SQL은 필요 없습니다**. 장비 개체의 `enhancement`/`failures`, 장비 저장소의 `stones`/최근 강화 이력100건, 새 탐험의 확정 확률/강화 단계/강화석만 추가합니다. 미정의 필드는+0/0개로 해석합니다. 과거 탐험의 결과는 소급 갱신하지 않습니다.

강화는 기존 operation ID·트랜잭션·revision 비교 재시도를 재사용합니다. 서버가 현재 장비와 자산을 읽어 비용/확률을 계산하고 암호학적 난수로 판정한 뒤 차감·결과·영수증을 원자적으로 저장합니다. 클라이언트가 보낸 단계/확률/비용은 신뢰하지 않습니다. 같은 요청의 재전송은 같은 결과를 반환합니다. 저장 실패 시 차감과 결과를 모두 롤백합니다.
