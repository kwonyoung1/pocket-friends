## 변경 내용

탐험이 가구 풀만 사용하던 구조를 수집용 보물과 별도 가구 보상으로 분리합니다. 희귀4종·전설5종 SVG 보물, 지역별 전설0/0/0.25/0.5% 확률, 기존 실제 판매액2배 및 희귀/전설 판매 확인을 추가합니다. 출발 시 확정한 기존 보상은 유지합니다.

새 음식4종과 고유 ID별 선호1.5/비선호0.8 배율을 적용하고 기존 +5 보너스 중첩을 제거합니다. 수동 휴식은 서버 시각으로 친구별4시간에 체력+20을 한 번 적용하며 자동 휴식·야간 수면을 유지합니다.

영단어 탐험은3×10문제, 채점 한 번, 힌트3회/단계, 출제 이력, 오답 노트·무보상 복습,2시간 제한·6시간 복구와 기기 간 이어하기를 제공합니다. 코인은 서버 채점 결과로 최대300을 한 번 지급합니다. **단어 데이터는90개(각 난이도30개)이며 목표5000개 중4910개는 후속 검수 범위**입니다. 전체 답안 은행은 운영 화면 번들에 포함하지 않습니다.

기존 저장 버전/ID/사진/개명/육성/코인/아이템/탐험/가구/햄스터를 보존합니다. 추가 SQL은 첫 새 버전 커밋 직전 월드를 트랜잭션 안에서 한 번 비공개 백업합니다. 클라이언트 프로토콜5로 갱신하고 구형 화면의 쓰기를 차단합니다. 방 내부 요소의 쌓임 범위를 제한해 가구 편집 버튼이 메뉴 클릭을 가로채던 문제도 수정합니다.

## 검증과 배포

`npm test`114개, `npm run test:e2e`76개, `npm run test:cloud`24개와 빌드·Deno 타입 검사가 통과했습니다. 마지막 영단어 화면 조정 후 관련 브라우저2개도 재검사했습니다. 전체 결과는 [검증 보고서](ADVENTURE_VERIFICATION.md)를 확인하세요. 브라우저 검사는 Chromium PC/모바일 터치 에뮬레이션이며 클라우드는 모의 API와 실제 SQL을 실행하는 PGlite로 검증합니다. 운영 데이터에는 접속하지 않았습니다.

**배포 순서:** 현재 추억 보관 → 기존 프로젝트에 `202610160001_adventure.sql`만 추가 적용 → 이 브랜치의 서버 수동 배포 → main 병합 → 자동 Pages 배포. 기존 secrets/variables/프로젝트를 재사용합니다. [클릭 가능한 초보자 배포 안내](ADVENTURE_UPDATE.md)를 따르세요. 새 SQL 적용 전 서버를 배포하거나 화면을 먼저 배포하지 마세요.
