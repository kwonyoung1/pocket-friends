## 개발 중 발견·수정

- 초기 모바일 화면에서 기존 sticky 메뉴가 사천성 위에 겹쳤습니다. 사천성 대화상자의 표시 순서를 올렸습니다.
- 패를 맞출 때마다 기존 전역 토스트가 보드 일부를 가려 모바일 연속 터치가 빗나갔습니다. 사천성 피드백을 게임 내부 상태 줄로 옮겼습니다.
- 자동 섞기 검사는 501ms에서 화면 갱신 주기(80ms) 이전 상태를 읽었습니다. 서버의 500ms 잠금은 별도 단위 검사로 정확히 검증하고 UI 검사에는 다음 갱신 프레임까지 기다리도록 했습니다.
- 대기 시간이 긴 시간 초과 검사는 프레임을 전부 실행하는 대신 백그라운드 경과를 재현하는 `clock.fastForward`를 사용합니다. 절대 종료 시각과 정산 금액 검증은 유지합니다.
- 첫 전체 회귀 실행은 90/92 통과했습니다. 나머지는 실행 중 코드 편집에 따른 개발 서버 새로고침과 브라우저 터치가 진행시킨 수십 밀리초를 고정값과 비교한 테스트 문제였습니다. 최종 실행에서는 소스 변경을 멈추고, 정확한 서버 시각 검증을 유지하면서 브라우저 측은 실제 입력 시간을 허용하는 범위 및 종료 후 불변성을 검사하여 92개 전부 통과했습니다.

## 검증 범위의 한계

- 실제 PC/휴대폰 운영 서비스, iOS Safari 실기기, Supabase 운영 배포는 직접 실행하지 않았습니다. Chromium의 데스크톱 및 iPhone 13 터치 에뮬레이션을 사용했습니다.
- 사용자별 익명 인증은 적용하지만 별도 기기의 익명 사용자를 동일 인물로 합치는 계정 연결은 없습니다.
- 서버는 합법적인 연결 순서와 서버 시간을 검증합니다. 사람과 자동 풀이 프로그램을 판별하는 기능은 아닙니다.
- v3 원본이 없어 수동 섞기 3회를 기본값으로 정했습니다.
