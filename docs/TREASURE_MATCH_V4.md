# 보물 3매치 v4 — 규칙과 구현

최신 main `e090831`(v2 병합)에서 기존 퍼즐을 확장했습니다. 30개 스테이지·특수 보석·이전 최고 기록·기존 육성 월드는 유지합니다. 무거운 3D 라이브러리나 새 앱 의존성은 추가하지 않습니다.

## 3초 콤보와 성과

성공한 직접 교환 한 번에 콤보 +1, 유지 시간은 **3,000ms**로 갱신합니다. 정확히 3초까지 이어지고 초과하면 끊깁니다. 무효 교환은 갱신하지 않으며 낙하 연쇄는 직접 콤보를 늘리지 않습니다. `performance.now()` 기준이며 폭발·낙하·리필·섞기·계산·일시정지·백그라운드에서는 카운트다운을 멈춥니다.

직접 점수 배율은 1/1.3/1.6/2/2.5/3/3.5/4/4.5/5, 11~14는 6, 15~19는 7, 20 이상은 8입니다. 기존 자동 연쇄 배율과 곱하되 최종 ×8 상한을 유지합니다.

한 판에서 최고 직접 콤보, 최장 연속 콤보의 **실제 조작 가능 시간**, 2콤보 이상으로 이어진 직접 교환의 총횟수를 기록합니다. 연속 기록이 끊어져도 최고값은 유지합니다. 20콤보를 2초씩 이어 가면 마지막 성공 순간까지 38초이며 이후에도 이어갈 수 있는 남은 창은 실제 경과한 만큼만 더합니다. 연출이나 일시정지 시간은 유지 보너스에 들어가지 않습니다.

## 도전 난이도

30초 시작·직접 매치마다 +5초·최대 30초·이동 횟수 무제한은 유지합니다. 시간 소모만 다음처럼 바뀝니다.

| Lv. | 점수 문턱 | 초당 소모 | 색상 |
| --- | ---: | ---: | ---: |
| 1 | 0 | 1.00 | 5 |
| 2 | 5,000 | 1.25 | 5 |
| 3 | 15,000 | 1.50 | 6 |
| 4 | 30,000 | 1.80 | 6 |
| 5 | 50,000 | 2.10 | 7 |
| 6 | 80,000 | 2.50 | 7 |
| 7 | 120,000 | 3.00 | 7 |

v2의 실제 문턱은 1,500~23,000점으로 요청서 표와 달랐으므로 이번 표로 변경했습니다. 기존의 최소 3회 성공 뒤 한 단계씩 상승하는 규칙은 유지하며 연쇄가 모두 끝난 뒤 반영합니다. 기존 구간을 소급해 빠르게 차감하지 않고 다음 조작 가능 시간부터 새 배율을 씁니다. Lv.7에서 실제 조작 가능 5초는 잔여 시간 15초를 소모합니다. 콤보의 3초는 난이도 배율을 곱하지 않습니다. Lv.7의 +5초는 실제 조작 가능 시간 약 1.67초에 해당하므로 그보다 빠르게 성공해야 잔여 시간을 유지할 수 있습니다.

보드는 점수 때문에 초기화하지 않고 기존 특수 보석·이미 만들어진 매치를 보존합니다. 안정된 도전 보드는 유효 교환 최소 2개를 유지합니다. 새 일반 보석의 보충/색상 분산을 조정하며 막히면 자동으로 섞고 그동안 시간은 차감하지 않습니다. 타이머에 배율을 표시하고 LEVEL UP 알림·테두리·기본 OFF인 소리를 켰을 때 짧은 경고음을 제공합니다.

## 실제 코인 보상

**공유 월드에서 서버 도전을 시작해 정상 시간 종료한 판만** 지급 대상입니다. 스테이지·연습·중도 종료·새로고침으로 끝난 진행 보드·예전 로컬 최고 기록에는 지급하지 않습니다. 성공 3회 미만의 판도 지급하지 않습니다. 시작 직후 종료를 반복해 보상받는 방식은 막습니다.

```
기본 = floor(서버 재계산 점수 / 250)
최종 = floor(기본 × 최고 콤보 코인 배율) + 최장 유지 보너스
```

| 최고 콤보 | 코인 배율 |
| --- | ---: |
| 1~4 / 5~9 / 10~14 / 15~19 | 1 / 1.3 / 1.7 / 2.2 |
| 20~29 / 30~39 / 40~49 / 50 이상 | 3 / 4 / 5 / 6 |

| 최장 조작 가능 콤보 유지 | 추가 코인(최고 구간 하나) |
| --- | ---: |
| 10 / 20 / 30 / 45 / 60 / 90초 이상 | 20 / 60 / 120 / 250 / 450 / 800 |

200,000점·32콤보·65초는 기본 800 + 콤보 2,400 + 유지 450 = **3,650코인**입니다. 소수 배율은 10분율의 정수 계산으로 처리합니다. 설정은 `src/match3/rules.ts`에 분리했습니다.

### 서버 검증과 원자적 지급

1. 별도 `treasure` Edge Function이 기존 로그인 JWT와 `game_members`의 유효한 입장 권한을 확인합니다. 기존 `game` 함수와 사천성 명령은 변경하지 않습니다.
2. 시작 요청 번호로 중복 시작을 막고 서버가 생성한 세션 ID·암호학적 난수 시드를 발급합니다. 새 시작은 계정당 10초 간격입니다.
3. 플레이 중에는 새 보상 API를 호출하지 않습니다. 교환 좌표·순서·조작 가능 경과 시간·단조 시각을 기록합니다. 클라이언트의 최종 점수/보상 숫자는 신뢰하지 않습니다.
4. 종료 후 서버가 같은 엔진·시드로 보드·점수·콤보·난이도·시간을 재계산합니다. 무효 교환, 시간 종료 뒤 입력, 역순/불가능한 시간, 다른 계정의 세션을 거절합니다. 시작/종료 시각은 서버 나이와 대조하고 각 교환 사이에 필요한 최소 연출 시간(모션 줄이기 기준)도 확인합니다.
5. Edge Function의 CPU 작업을 제한하기 위해 한 요청에 최대 80개 교환씩 검증합니다. 이어지는 체크포인트와 제출 SHA-256은 서비스 역할만 접근하는 DB에 보관합니다. 정산 재요청은 같은 기록을 이어 검증하며 도중에 다른 기록으로 바꿀 수 없습니다.
6. 검증 완료 후 SQL이 세션 행과 최신 월드 행을 잠그고 **코인 덧셈·revision 증가·지급 완료 기록을 한 트랜잭션**으로 처리합니다. 기존 월드 전체를 클라이언트 저장본으로 교체하지 않습니다. 실패하면 둘 다 원복하며 동시 요청/응답 유실 후 재시도는 기존 영수증을 돌려줍니다.
7. 기존 월드 갱신 명령이 오래된 revision으로 도착하면 기존 CAS 규칙에서 충돌 처리되어 새 코인을 덮어쓰지 않습니다. 기존 동기화 코드를 수정하지 않고 검증했습니다.

보상 검증 한도는 한 판 최대 **2,000회 성공 교환·12시간·요청 450KB**입니다. 무제한 플레이 자체를 강제 종료하지는 않지만 한도를 넘은 판은 코인 지급이 안 되며 로컬 기록만 남습니다. 도움말에도 표시합니다. 서버 검증은 가능한 보드와 시간의 재현을 확인하는 방식이며 자동화 봇/사람 판별을 보장하지 않습니다.

정산 전에는 **보상 확인 중**, 서버 확정 뒤에만 **보상 지급 완료**와 확정 코인을 보여 줍니다. 응답 유실 시 제출 기록은 별도 로컬 키에 보관하며 **보상 다시 확인**으로 재시도합니다. 이미 지급된 세션은 재지급하지 않습니다. 로그인한 원래 기기 계정으로 확인해야 합니다. 오래되었거나 거절된 기록은 **기록 보관 후 대기 정리**에서 사용자 확인 후 JSON으로 내려받고 대기를 비울 수 있습니다. 기존 육성 데이터·실제 코인에는 손대지 않습니다.

## 그래픽과 조작

루비 팔각·사파이어 물방울·에메랄드 직사각 컷·자수정 크리스털·토파즈 마름모·다이아몬드 브릴리언트·호박석 타원 실루엣을 유지/보정하고 다면체 반사·어두운 측면·가장자리·굴절 선과 하이라이트를 추가했습니다. 공유 SVG 심볼을 사용합니다.

선택 1.12배 확대, 손가락/마우스를 따라 움직이는 보석, 최대 9도 기울기, 이웃 교환 대상 반응, 빛 잔상을 적용합니다. 포인터 이동은 CSS 변수와 transform만 바꾸며 매 프레임 React 상태를 갱신하지 않습니다. 취소·포커스 이탈 시 잡힌 효과를 정리합니다.

3초 게이지와 큰 콤보 숫자, GREAT / AMAZING / FANTASTIC / UNSTOPPABLE / LEGENDARY / GODLIKE 안내, 황금·에너지·전설 강조를 적용합니다. 기존 풀링 파편·충격파·특수 보석 빔·보드 전용 최대 5px 흔들림은 유지하며, 높은 확정 보상에는 코인/황금 효과와 숫자 카운트업을 추가합니다. 강도·흔들림·모션 줄이기 설정은 그대로 사용할 수 있습니다.

## 보존과 배포

육성 월드·캐릭터·사진·탐험·장비·가구·영단어·사천성·기존 CloudClient와 서버 명령은 보존합니다. 퍼즐 중 배경 방 그리기만 쉬고 기존 월드 동기화와 탐험 서버 시간은 계속됩니다. 종료하면 최신 월드를 다시 읽습니다.

스테이지 해금·점수와 v2 도전 기록을 유지하고 새 성과 필드만 추가합니다. 예전 기록을 실제 보상으로 변환하지 않습니다. v4의 실제 코인 보상은 신규 SQL과 **별도 treasure 서버 배포**가 필요합니다. [누를 버튼별 배포 안내](TREASURE_MATCH_V4_DEPLOY.md) · [검증 보고서](TREASURE_MATCH_V4_VERIFICATION.md)
