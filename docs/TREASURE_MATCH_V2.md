# 보물 3매치 v2 — 사용법과 구현 규칙

메인 화면의 **💎 보물 3매치**에서 **스테이지 모드** 또는 **도전 모드**를 선택합니다. 30개 스테이지의 목표·이동 횟수·얼음·해금 기록은 유지합니다. 도전 모드는 이동 횟수나 목표 점수 없이 시간과 최고 기록에 도전합니다.

## 5초 직접 콤보

두 모드 모두 **플레이어가 성공시킨 교환 한 번에 직접 콤보 +1**입니다. 한 교환 뒤 저절로 일어나는 연쇄는 직접 콤보를 늘리지 않습니다. 다음 성공 교환까지 입력 가능한 시간이 정확히 5초 이내이면 이어지고, **5초를 초과하면 끊깁니다**. 무효 교환은 콤보를 늘리거나 5초를 갱신하지 않습니다.

시간은 `performance.now()`로 계산합니다. 계산·교환·폭발·낙하·보충·자동 섞기·일시정지 중에는 콤보 시간이 줄지 않습니다. 탭을 숨기면 자동 일시정지하고 돌아와 **계속하기**를 눌러야 합니다. 재시작·모드 전환·게임 종료는 콤보를 초기화합니다.

| 직접 콤보 | 배율 |
| --- | ---: |
| 1 / 2 / 3 / 4 / 5 | 1 / 1.3 / 1.6 / 2 / 2.5 |
| 6 / 7 / 8 / 9 / 10 | 3 / 3.5 / 4 / 4.5 / 5 |
| 11~14 / 15~19 / 20 이상 | 6 / 7 / 8 |

기존 자동 연쇄 배율 1·1.5·2·3·4·5와 곱하고 **최종 배율을 최대 8로 제한**합니다. 제거된 보석 ID는 같은 제거 단계에서 중복 계산하지 않습니다. 점수는 정수로 반올림합니다. HUD의 큰 숫자는 직접 콤보이며, 보드의 연쇄 안내는 자동 연쇄입니다.

HUD는 파랑(1~2)·보라(3~4)·금색(5~7)·불꽃(8~9)·무지개(10~19)·전설(20 이상)로 바뀝니다. 5초 게이지는 약 0.1초마다 갱신하고, 2초 이하에서 붉게, 1초 이하에서 약하게 깜박입니다. 보드가 흔들려도 HUD는 흔들리지 않습니다.

## 도전 모드의 시간과 기록

- 30초 시작, 유효한 **직접 교환마다 +5초 한 번**, 최대 30초입니다. 연쇄·특수 보석에 맞아 제거된 횟수는 추가 시간을 주지 않습니다.
- 잔여 시간이 0이면 새 입력을 받지 않습니다. 시간 내 확정된 교환은 모든 점수 정산을 끝냅니다.
- 시간은 입력 가능한 상태에서만 줄어듭니다. 애니메이션·자동 섞기·계산·일시정지는 차감하지 않습니다.
- 도전 모드의 **기록 생존 시간은 입력 가능한 누적 시간**입니다. 연출·무효 교환 애니메이션·일시정지로 기록을 늘릴 수 없습니다. 결과에서 **연출 포함 플레이 시간**도 별도로 보여 줍니다. 따라서 현실에서 5분 플레이한 것과 기록 생존 5분은 다릅니다.
- 최고 점수·생존 시간·직접 콤보·최고 난이도와 최근 10판을 로컬에 저장합니다. 종료·재시작·모드 변경은 진행한 판을 종료 기록으로 남깁니다. 새로고침 시에도 완료한 이동의 기록을 보관하지만 **진행 중 보드 자체를 재개하지는 않습니다**.
- 스테이지의 무료 힌트는 그대로 유지합니다. 도전 모드는 무제한 정답 제시로 시간 제한을 무력화하지 않도록 **힌트 없이** 진행하며 시작 화면과 도움말에 표시합니다.
- 5분 강제 종료, 무작위 실패, 몰래 시간 차감, 숨겨진 보상 제한은 없습니다. 빠르고 정확한 플레이는 계속 이어질 수 있습니다.

## 점수에 따른 난이도

| 난이도 | 진입 점수 | 색상 | 새 보드·보충에서 목표로 하는 유효 교환 후보 수 |
| --- | ---: | ---: | ---: |
| 1 | 0 | 5 | 5 |
| 2 | 1,500 | 5 | 5 |
| 3 | 3,500 | 6 | 4 |
| 4 | 6,500 | 6 | 4 |
| 5 | 10,500 | 7 | 3 |
| 6 | 16,000 | 7 | 3 |
| 7 | 23,000 | 7 | 2 |

점수를 넘더라도 현재 난이도에서 최소 3회 유효 교환을 마치고 연출이 끝난 뒤 **한 단계씩** 올라갑니다. 색상 증가는 이후 보충에 적용하며 기존 보드를 점수 때문에 초기화하지 않습니다.

안정된 도전 보드에는 실제 유효 교환을 최소 2개 보장합니다. 새 보드/막힌 보드의 섞기는 제한 횟수 안에서 목표 후보 수에 가까운 배치를 찾습니다. 보충 최적화는 **이번에 새로 생성된 일반 보석만 화면 표시 전에 조정**하며 기존 보석·특수 보석·이미 만들어진 매치는 손대지 않습니다. 후보 2~5개는 목표이지 모든 특수 보석 조합에서의 강제 상한은 아닙니다. 후보가 이미 많은 정상 보드를 난이도 때문에 강제 리셋하지 않습니다.

입력 가능 누적 3분 이후 후보 목표는 2개, 4분 이후에는 새 보석의 색상 분산을 강화합니다. 점수·배율·+5초 규칙은 바꾸지 않습니다. 난이도와 배율은 `src/match3/config.ts`에서 조정합니다.

## 이펙트와 성능

보석별 파편·선명한 짧은 섬광·충격파, 직선 빔·번개·무지개·특수 조합 효과, 특수 보석 생성 팝, 묶음 점수 팝업을 사용합니다. 2,000점 이상 한 수·5/10/20콤보·신기록 배너를 표시합니다.

보드 흔들림은 최대 5px·140ms이며 HUD·전체 페이지는 흔들지 않습니다. 전체 섬광은 낮은 강도로 한 교환에 최대 한 번입니다. **흔들림 ON/OFF**, **이펙트 강도 부드럽게/보통/강하게**, 기본 OFF인 **소리** 설정을 제공합니다. 운영체제의 모션 줄이기 설정은 강한 효과보다 우선합니다.

Canvas 파티클과 충격파를 재사용하고 화면 크기·느린 프레임에 따라 수를 줄입니다. 긴 자동 연쇄는 논리 점수·제거 계산을 모두 끝낸 뒤 시각적 폭발을 최대 4묶음으로 압축해 전체 연출을 약 1초로 제한합니다. 중간 연출 일부를 합칠 뿐 최종 보드와 점수를 생략하지 않습니다. HUD는 별도 구독으로 갱신해 매 0.1초마다 보드 전체를 다시 그리지 않습니다.

## 기존 데이터와 동기화

육성 월드·캐릭터·사진·장비·코인·사천성·영단어·Supabase 서버·SQL은 변경하지 않습니다. 퍼즐 중 기존 공유 월드 동기화는 계속되며 방의 애니메이션만 쉬고, 나가면 최신 월드를 다시 받습니다. 퍼즐에는 코인·아이템·경험치 보상이 없습니다.

기존 로컬 키 `pocket-friends-treasure-match-v1`의 해금·스테이지 최고 점수·소리 설정을 읽고 새 필드만 추가합니다. `pocket-friends-treasure-match-challenge-v2`에는 도전 기록과 연출 설정을 추가 보관합니다. 이전 버전 탭이 구 저장 키를 덮어도 새 도전 기록을 복원하며 탭 간 최고 기록은 최대값으로 병합합니다. 최근 기록은 판 ID로 중복 제거합니다. 저장이 차단되면 게임은 실행하지만 저장 실패를 알립니다.

**육성 월드는 PC·모바일 공유, 3매치 기록은 브라우저별 로컬 저장**입니다. 신규 SQL이나 데이터 초기화는 필요하지 않습니다. [배포 순서](TREASURE_MATCH_V2_DEPLOY.md) · [검증 및 측정](TREASURE_MATCH_V2_VERIFICATION.md)
