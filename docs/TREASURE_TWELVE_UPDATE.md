# 보물 3매치 v5: 12단계와 프리즘 이펙트

새 도전부터 12단계로 진행합니다. 이전 판과 미지급 기록은 그 판의 원래 규칙으로 검증합니다. 화면의 업데이트 이름은 v5이며, 보상 프로토콜은 기존 내부 규칙 5와 구별하기 위해 **6**입니다.

한 수의 연쇄가 모두 끝나면 점수에 맞는 단계로 올라갑니다. 승급 자체는 남은 시간을 깎지 않습니다. 30초 시작, 직접 성공 +5초/최대30초, 실제 판단 시간 기준 3초 콤보, 배율 최대8을 유지합니다. 연출·셔플·일시정지에는 두 시계가 멈추고 백그라운드에서는 일시정지합니다. 새 보드와 정리된 보드는 최소2개 교환을 확보합니다. 새 색상은 이후 보충 시 들어오며 기존 보석을 승급 때문에 교체하지 않습니다.

## 무료 이펙트 선택

**추가 라이브러리 0개. 기존 자체 Canvas 2D 엔진을 확장했습니다.** 브라우저 API이므로 별도 API 요금·구독·런타임 CDN·외부 애니메이션 에셋이 없습니다. package.json/package-lock.json과 기존 라이선스 고지를 유지합니다. 추가 외부 라이선스 고지는 없습니다.

기존 코드와 용도 기준의 후보 검토:

| 후보 | 적합한 용도 | 이번 선택 |
|---|---|---|
|[GSAP](https://gsap.com/)|타임라인·탄성·점수 애니메이션|기존 CSS/RAF가 이미 같은 역할 수행. 추가하지 않음|
|[tsParticles](https://github.com/tsparticles/tsparticles)|다양한 입자·이미터|고정64칸/상한160입자에는 기존 풀이 간단함. 추가하지 않음|
|[canvas-confetti](https://github.com/catdad/canvas-confetti)|축하용 입자|제거 범위에 맞춘 광선·파편은 별도 구현이 필요하므로 추가하지 않음|
|[dotLottie](https://github.com/LottieFiles/dotlottie-web)|제작된 벡터 애니메이션|플레이 결과마다 변하는 표적에는 기존 Canvas가 적합. 개별 에셋도 불필요|

미채택 패키지를 설치해서 동일 기기 벤치마크한 것은 아닙니다. 기존 Canvas의 호환성과 실제 연출·프레임을 검증하여 채택했습니다. 후보 라이선스를 프로젝트에 추가하지 않았습니다.

## 실제 연출

- 일반 제거: 220ms 밝기/1.2배 확대, 별 섬광, 회전하는 삼각 유리 파편·별·작은 반사광, 230ms 충격파.
- 4~5개 제거: 입자 밀도 증가, 특수 생성 지점에 에너지 링.
- 10/20개 이상: 더 빠르고 큰 파편, 넓은 이중 충격파. 기존 흔들림·대형 점수 효과 유지. 큰 제거에서는 작은 점수들이 겹치지 않게 중앙 합산 팝업을 사용합니다.
- 관통: 색 광선 외곽과 가는 흰 중심, 실제 표적을 연결. 폭발/무지개/번개/특수 조합도 기존 효과의 실제 origin/targets를 그대로 사용합니다. 제거·점수 판정은 Canvas에서 하지 않습니다.
- 직접5콤보 황금 입자, 10콤보 무지개 입자, 황금/무지개/전설 숫자 주변 에너지 링. 기존 단계별 배너와 점수 카운트업 유지.
- 보석 SVG: 내부 굴절면, 보라/노랑 프리즘 반사, 흰 모서리 광택 추가. 기존 각기 다른 형태·그림자 유지.
- 선택 시 떠오름·그림자, 드래그 방향 기울기/밝은 잔상/별빛, 대상 보석 반응. 기존 transform 직접 추종·교환 성공/실패 동작 유지.
- Lv8~9는 주황 테두리, Lv10~12는 어두운 자주/붉은 테두리. 승급 소리는 소리 ON인 경우 재생하며 강한 점멸을 새로 추가하지 않았습니다.

아래 이펙트 설정에서 강하게/보통/부드럽게를 선택합니다. PC 입자 상한은160/96/48, 터치 기기는96/58/29입니다. 느린 프레임이 누적되면 장식 입자를32 이하로 축소합니다. reduced-motion은 입자와 추가 회전 효과를 끕니다. 설정은 기존 저장 키를 사용합니다.

## 보상과 기존 데이터

main의 실제 기본 코인은 **floor(점수 /500)**입니다. 요청서의 /1500은 예시이므로 변경하지 않았습니다. 기존 높은 게임 점수, 콤보·유지 보너스, 서버 시드/재생검증/동시 정산 방지/유저 검증/비공개 체크포인트를 그대로 사용합니다. 난이도 보너스는 추가하지 않습니다.

새 SQL은 새 판을 rules=6으로 발급하는 함수만 교체합니다. 기존 월드·보상 행을 갱신/삭제하거나 Supabase를 초기화하지 않습니다. 내부4/5 판은 원래 색상·난이도·시간/코인 규칙으로 정산합니다. 기존 저장키와 미지급 JSON 키도 유지합니다. 최고 난이도 저장 상한만7→12로 확장했습니다.

사천성, 영단어, 월드 동기화, 캐릭터, 탐험, 장비, 상점, 일괄 돌봄의 제품 코드는 변경하지 않았습니다. 테스트용 클라우드 fixture만 새 서버 규칙으로 시작하도록 변경했습니다.
