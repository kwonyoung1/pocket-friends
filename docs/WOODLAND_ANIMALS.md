# 동물 4족 보행·토끼 도약·수채화 거실 실제 구현

## 작업 기준과 보존 범위

기능 브랜치는 `feat/woodland-quadruped-animation`입니다. 작업 시작 시 최신 main은 `91c4153`이었으며 이전 페인팅 원화 작업 `7211afe`가 아직 병합되지 않아 그 커밋에서 이어 작업했습니다. 따라서 이번 PR은 이전 미병합 원화/거실 개선도 포함합니다. 이번 새 브랜치를 main에 병합하면 앞선 원화 작업을 별도로 먼저 병합할 필요가 없습니다.

**영이·찬미의 작업 시작 당시 사람 원화·이미지 파일·HumanSprite·humanPose는 수정하지 않았습니다.** 사람은 기존 2족 보행을 사용합니다. 사진이 등록된 캐릭터는 `Character`의 첫 번째 분기에서 여전히 개인 사진을 표시합니다. 개인 사진을 동물 원화로 덮어쓰거나 4족 이미지로 재생성하지 않았습니다.

이번 동물 작업은 이동 좌표/경로/충돌, 코인/인벤토리/탐험/장비/돌보기 수치, 저장 스키마와 Supabase 서버, 사천성·보물 3매치 로직을 수정하지 않습니다. 가구·보물 배치를 초기화하지 않습니다. 동작 위상·무작위 생활 포즈는 로컬 화면 표현이며 저장·서버 판정값을 추가하지 않습니다.

## 실제 새 원화

|종류|실제 파일 경로|기본 이동|
|---|---|---|
|고양이|`src/assets/animals/cat/`|수평 몸통의 네 다리 교대 보행|
|토끼|`src/assets/animals/bunny/`|웅크림 → 뒷발 밀기 → 도약 → 앞발 착지 → 뒷발 회수|
|강아지|`src/assets/animals/dog/`|크림색 강아지의 네 발 보행|
|곰|`src/assets/animals/bear/`|두툼한 발과 수평 몸통의 느린 네 발 보행|
|여우|`src/assets/animals/fox/`|날씬한 네 다리와 풍성한 꼬리의 가벼운 보행|

각 폴더에는 실제 파일 `walk-0.webp`~`walk-7.webp` 8개와 `idle.webp`, `blink.webp`, `sit.webp`, `sleep.webp`, `stretch.webp`, `groom.webp`, `yawn.webp`, `look.webp` 8개가 있습니다. 전체 **이동 40프레임 + 생활 40포즈**입니다. 기본 `idle.png`도 5개 포함했습니다. 런타임은 이 프레임들을 담은 `walk-atlas.webp`, `life-atlas.webp` 10개를 사용합니다.

동물이 사람처럼 허리를 세우고 걷던 이전 원화는 기본 동물 렌더링에서 제외했습니다. 기지개·세수·그루밍 중 잠깐 앞발을 드는 동작은 실제 동물 자세이며 기본 이동은 네 발입니다.

새 image_gen 원화입니다. 손으로 직접 그린 그림, 기존 작품에서 추출한 이미지 또는 원본 한 장에 없던 자세를 추출한 결과라고 주장하지 않습니다. 기존 고양이의 색/얼굴과 자체 방 구도를 참고했고 특정 애니메이션 작품의 캐릭터나 장면을 복제하지 않았습니다. 새 원본 PNG 11개와 출처·사용 조건은 [원화 출처 및 라이선스](../art-source/woodland/LICENSE.md)에 기록했습니다. 외부 스톡·유료 리소스는 포함하지 않았습니다.

원본 시트는 1536×1024, 4열×2행이며 **개별 원본 칸은 384×512**입니다. 게임용 칸은 공통 기준점과 여백을 가진 512×512로 정규화했습니다. 원본 칸이 가로 512px 이상이었다고 주장하지 않습니다. 사람 원화는 정규화 과정에서도 건드리지 않았습니다.

고양이 생활 시트의 불투명 배경과 강아지·곰의 칸 경계에 닿은 발끝은 이미지 생성 편집으로 수정했습니다. 최종 채택한 80개 원화는 원본 칸 경계 불투명 픽셀 0, 출력 투명 가장자리, 해시와 프레임 크기 검사를 통과했습니다. 연속 이동 프레임마다 아래쪽 실루엣이 실제로 다른지도 검사합니다.

## 보행과 상태 전환

`src/animals/motion.ts`는 저장 객체를 수정하지 않는 화면용 상태기계입니다. `AnimalSprite`가 실제 친구의 x/y·moving·facing·교감·수면 상태를 읽습니다.

|상태|실제 표시|
|---|---|
|Idle|네 발 대기, 불규칙 깜빡임·생활 포즈|
|WalkStart|160ms 동안 대기에서 실제 이동 프레임으로 전환|
|Walk|실제 이동 거리에 따라 8칸 진행|
|WalkFast|기본 종별 속도의 1.2배를 넘는 관측 속도. 같은 8프레임이 실제 거리만큼 빠르게 진행|
|Turn|140ms 동안 주변 살피기 포즈를 섞어 체중·머리 방향 전환을 완화|
|WalkStop|마지막 걸음 프레임을 멈추고 180ms 동안 대기로 전환|
|Sit|실제 그려진 앉기 포즈|
|Rest|확정된 가구/수동 휴식 중 앉기 포즈|
|Sleep|실제 그려진 웅크린 수면 포즈|
|WakeUp|320ms 동안 앉은 포즈를 거쳐 일어남|
|Drag|보행 위상 정지, 기존 드래그 들어 올리기/놓기 유지|

보행 위상은 `누적 실제 이동 거리 / 종별 한 주기 거리 × 8`로 계산합니다. 단순 시간 루프가 아니므로 같은 자리에 있으면 발 프레임이 진행하지 않습니다. 한 주기 거리는 고양이 40, 강아지 36, 곰·여우 44, 토끼 28 월드 단위입니다. 곰의 기존 실제 이동속도 29, 여우 42, 나머지 35는 수정하지 않았습니다. 속도 판정은 120ms 이상 구간의 관측값을 완화해 게임 갱신 주기와 rAF 주기의 차이로 빠른 걷기가 잘못 선택되지 않도록 했습니다.

64단위 이상의 동기화 위치 보정, 긴 갱신 공백과 탭 복귀는 실제 걸음으로 계산하지 않습니다. 드래그 거리도 보행 위상에 더하지 않습니다. 그림 전체를 상하로 흔드는 것을 새 보행이라고 표시하지 않습니다. 작은 호흡은 비율을 유지한 균일 확대이며 걷기는 실제 새 자세들입니다.

## 방향과 생활 동작의 구현 범위

**현재 전용 원화는 오른쪽을 향한 옆/비스듬한 시점이며 왼쪽은 좌우 반전입니다. 앞·뒤 전용 이동 원화는 아직 없습니다.** 위아래로 이동할 때도 실제 옆모습을 유지합니다. 그림을 회전시켜 뒷모습인 척하지 않습니다. 상태 구조는 앞/뒤 이동 방향을 구분하므로 추후 별도 원화를 추가할 수 있습니다.

대기 동작은 캐릭터별로 4~10초 간격을 따로 정합니다. 고양이는 기지개/세수, 강아지는 갸웃/하품, 곰은 앉기/졸기, 여우는 살피기/기지개, 토끼는 앞발 모으기/귀를 세운 살피기 등을 선택합니다. 깜빡임은 별도 불규칙 간격입니다. 귀·꼬리와 몸통의 변화는 새 원화 프레임에 그려진 변화입니다. 귀·꼬리를 독립 관절로 제어하는 리깅이나 연속적인 자유 시선 추적은 구현하지 않았습니다. WakeUp/Turn은 별도 전용 전환 시트가 아니라 확보한 실제 앉기/살피기 포즈를 중간에 사용합니다.

## 실제 방 배경

`src/assets/room/woodland-watercolor.webp`가 실제 `RoomArt`에 연결됩니다. 기존 방 구도를 기준으로 창밖 숲/하늘, 린넨 커튼, 수채화 원목 바닥, 세이지 소파, 러그, 원목 책장·테이블·식물과 자연광을 새로 제작했습니다. 현재 버튼/상태 패널 구조는 유지합니다.

방의 **기본 장식 가구와 벽·바닥은 새 정적 배경 그림**입니다. 사용자가 배치한 가구·보물은 여전히 독립 `RoomExtras`이며 기존 좌표/이동/회수/층을 사용합니다. 새 배경 안으로 사용자 데이터를 합성한 목업이 아닙니다. 배경 속 장식 벽시계는 그림이고 실제 시간은 기존 한국 시간 UI 시계가 표시합니다. 할로윈 변경과 기존 테마 장식, 밤 분위기도 유지합니다.

## 성능과 검증

- 10개 런타임 동물 아틀라스 합계 약 **2.37 MiB**, 방 WebP 약 344 KiB입니다. 기본 PNG URL은 검수용 속성이며 기본 화면은 WebP 아틀라스를 사용합니다.
- 큰 생성 원본 PNG와 개별 80개 리뷰용 WebP는 프로덕션 진입점에서 import하지 않습니다. 아틀라스는 종별 공유·사전 로딩하며 프레임마다 네트워크 요청을 만들지 않습니다.
- 새 렌더러는 동물 수와 무관하게 **공용 rAF 루프 1개**, 최대 30Hz로 실제 프레임을 갱신합니다. React를 매 프레임 setState하지 않습니다. 캐릭터마다 Pixi 앱을 생성하지 않습니다.
- IntersectionObserver로 화면 밖의 갱신을 중지하고 탭이 숨겨지면 공용 rAF를 중단합니다. 생활 모션 줄이기와 reduced-motion에서는 보행을 재생하지 않습니다. 호흡도 화면 밖·백그라운드·감소 모션에서 중단합니다.
- `npm run check:animal-art`: 실제 80프레임 투명도/크기/원본 칸 여백/해시와 40개 보행 인접 전환 실루엣 차이 통과.
- 관련 단위 테스트: 8파일 **90개 통과**. 거리 기반 재생, 빠른 이동, 시작/정지/Turn, 드래그/보정 제외, 잠깨기, 입력 비변경 포함.
- 기존 브라우저 회귀 **36개 통과**, 새 동물 시나리오 **6개도 최종 통과**했습니다. 모바일에서 화면 밖 중단이 작동하는 점을 반영해, 가시성 검사와 입력 검사는 보이는 캐릭터를 대상으로 분리했습니다. 개인 사진 크롭/복구, 이름, 실제 포인터/터치, 돌보기 수치·하트·쿨타임, 수면, PC/모바일 반응형을 확인했습니다.
- 클라우드 핵심 회귀 **6개 통과**: PC/모바일 공유 구매 멱등성, 사람 이름/사진/개별 친밀도, 음식/휴식 동기화. 운영 DB를 대상으로 실행한 검사는 아닙니다.
- TypeScript/Vite 빌드 및 영단어 데이터 제외·이펙트 격리 검사 통과. 관련 없는 미니게임 전체 테스트는 실행하지 않았습니다.

## 실제 화면과 보행 영상

다음은 실제 App을 촬영용 새 로컬 저장 데이터로 실행한 화면입니다. 기존 캐릭터 4명과 실제 입양 목록의 강아지, 특별 지급 사람 2명을 사용합니다. 촬영용 기본 이름/잔액은 운영 계정의 이름·데이터를 변경한 결과가 아닙니다.

- [PC 화면](screenshots/woodland-home-desktop.png)
- [모바일 화면](screenshots/woodland-home-mobile.png) · [모바일 오른쪽 공간](screenshots/woodland-right-mobile.png)
- [PC 실제 보행 영상](demos/woodland-walking-desktop.webm)
- [모바일 실제 보행 영상](demos/woodland-walking-mobile.webm)
- [브라우저 관측 기록](demos/woodland-browser-observations.json): 실제 위치 이동량·관측 프레임·상태·rAF 간격·페이지 오류

실제 거실 녹화에서 PC·모바일 각각 5종 모두 0~7번 프레임이 관측됐고 페이지 오류는 없었습니다. 녹화 중 rAF 관측 평균은 PC 약 46Hz, 모바일 뷰포트 약 60Hz이며 95백분위 간격은 각각 약 33.5ms/16.7ms입니다. 이는 보행 프레임 수나 실물 휴대전화 FPS와 다른 지표이며 화면 캡처·영상 인코딩을 포함한 개발 호스트 관측입니다. 화면 밖에서 아직 시작되지 않은 포즈는 관측 기록에 null로 남습니다.

정지 스크린샷만으로 보행을 확인했다고 주장하지 않습니다. 기록된 rAF 수치는 개발 호스트의 헤드리스 Chromium 참고치이며 실제 저사양 휴대전화의 GPU/FPS/발열 측정값이 아닙니다.

## 수정 파일과 재현

- `src/Character.tsx`: 개인 사진/사람 분기를 유지하고 동물만 새 렌더러로 연결.
- `src/animals/{AnimalSprite.tsx,motion.ts,scheduler.ts,styles.css,assets.ts}`: 원화 등록, 거리/상태, 공용 스케줄러, 아틀라스 표시.
- `src/Room.tsx`, `src/room/theme.css`: 새 수채화 기본 배경과 기존 테마 장식.
- `src/assets/animals/*`, `src/assets/room/woodland-watercolor.webp`: 실제 새 에셋.
- `art-source/woodland/*`: 실제 생성 원본·출처·메타데이터.
- `scripts/prepare-animal-art.mjs`, `check-animal-art.mjs`, `capture-woodland.mjs`: 에셋 재현·검증·실제 영상 촬영.
- `src/animals/motion.test.ts`, `tests/animals.spec.ts`, `tests/interactions.spec.ts`: 새 상태와 기존 돌보기 회귀.
- `tests/fixtures/animals.*`: 제작 원화 열람용이며 프로덕션 화면이 아님.

저장소 루트에서 `npm run prepare:animal-art`, `npm run check:animal-art`를 실행할 수 있습니다. `npm run dev -- --port 4173` 실행 후 `node scripts/capture-woodland.mjs`로 실제 로컬 App 영상을 재촬영할 수 있습니다. 영상 촬영에는 Playwright용 FFmpeg 또는 호환되는 기존 시스템 FFmpeg가 필요하며, 이번 촬영은 새 다운로드 없이 설치되어 있던 시스템 FFmpeg를 사용했습니다.

## PR 병합·배포 순서

1. GitHub 로그인 후 [이번 새 브랜치 PR 만들기](https://github.com/kwonyoung1/pocket-friends/compare/main...feat/woodland-quadruped-animation?expand=1)를 엽니다. **base: main**, **compare: feat/woodland-quadruped-animation**을 확인하고 **Create pull request**를 누릅니다. 이미 이 브랜치 PR이 있으면 그 PR을 엽니다.
2. PR **Checks**가 모두 초록색이 될 때까지 기다립니다. 실패하면 해당 로그를 확인합니다. 노란색 실행 중에 중복 실행할 필요는 없습니다.
3. PR **Conversation** 아래 **Merge pull request → Confirm merge**를 누릅니다.
4. [Test and deploy Pocket Friends](https://github.com/kwonyoung1/pocket-friends/actions/workflows/deploy.yml)를 엽니다. 병합 후 자동 시작된 **main** 실행에서 **build와 deploy가 둘 다 초록색**인지 확인합니다. 자동 실행됐다면 **Run workflow를 또 누르지 않습니다**.
5. 자동 실행이 없다면 같은 화면에서 **Run workflow → Branch: main → Run workflow**를 한 번 누릅니다.
6. [게임 열기](https://kwonyoung1.github.io/pocket-friends/)에서 PC **Ctrl+Shift+R**, 모바일은 탭을 닫았다가 다시 열어 확인합니다. 데이터나 사이트 저장 공간을 삭제하지 마세요. 기존 등록 사진 캐릭터는 사진이 계속 표시됩니다.
