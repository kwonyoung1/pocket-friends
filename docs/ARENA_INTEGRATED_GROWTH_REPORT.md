## 특별 패시브

영이 ATK +20: 원래 타격마다 추가 70%, +30: 85%. 기존 주 대상 추가 타격도 포함해 1타→2타, 원래 2타→4타, 3타 광역→대상별 6타입니다. 원래 타격의 방어/속성/치명타 계산 후 추가 타격 계수를 적용하고 HP/보호막/총 피해에 반영합니다. 처치 후 중단하고 속성 공명/마스터리/추가 행동을 재귀 실행하지 않습니다. 비공격 지휘 스킬은 제외합니다. 잔상·추가 피해 숫자·푸른 별빛을 표시합니다.

찬미 DEF +20: 실제 보호막을 부여한 대상마다 직접 피해 1회 완전 차단, 대상 행동 기준 2턴. +30: 3턴, 차단 후 최대 HP 4% 작은 보호막(기존 최대 HP 60% 보호막 상한 유지). 최대 한 충전만 갱신하며 다단 공격 첫 개별 타격만 막습니다. 차단 시 기존 HP/보호막은 소모되지 않으며 빗나감/지속 피해는 충전을 소비하지 않습니다. 강화 해제로 제거될 수 있습니다. 회복 스킬의 부가 보호막도 포함합니다. UI에서 가호와 완전 차단을 표시합니다.

기존 +10은 예고, 해당 능력치 +20부터 패시브입니다. ATK/DEF/HP 모두 +20이라는 종합 육성 기준과 개별 패시브 해금을 구분합니다. 기존 저장 단계를 즉시 인정하며 별도 재화/중복 캐릭터를 요구하지 않습니다. 기존 액티브 해금 Lv.20/35/50을 유지합니다.
