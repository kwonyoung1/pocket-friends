## 새로 검증한 내용

- 이름을 바꿔도 고정 ID의 특별 친구만 혼잣말합니다. 일반·입양 친구는 인사할 때 말 대신 몸짓을 하며, 터치나 돌봄 필요 상태에서는 대사를 출력합니다.
- 한국 시간대와 상대의 실제 이름을 사용합니다. 긴급 상태와 직접 교감이 평상시 대사보다 우선합니다. 특별 친구 대화는 순서대로 표시합니다.
- 일반·특별·상세 패널의 쓰다듬기가 한 친구의 정확히 360분 제한을 공유합니다. 6시간 직전은 불가, 경계 시점은 가능하며, 제한 중에는 친밀도·행복·XP·미션 보상이 늘지 않습니다.
- 두 기기의 동시 쓰다듬기는 실제 PostgreSQL 잠금/버전 비교를 거쳐 한 번만 보상합니다. 기기가 전송한 가짜 시간은 무시하고, 화면의 남은 시간도 서버 기준입니다.
- 새로고침 후 쿨타임, 사진, 이름, 성장, 지갑, 재고, 잠긴 탐험 결과, 배치 가구, 햄스터, 진행 중 목욕, 감기 및 개명 제한을 보존합니다. 원본 객체도 변경하지 않는지 검사합니다.
- 배고픔/청결/체력 아이콘, 심한 먼지 효과, 기본 동물의 졸린 눈, 상태별 속도 감소 및 휴식 뒤 이동 재개를 확인합니다. 모바일 가로 넘침을 검사하고 화면도 직접 확인했습니다.
- 상태 알림은 가장 긴급한 상태부터, 같은 상태 15분 간격으로 출력합니다. 서버가 타임스탬프를 보관하고 새로고침 시 복원합니다. 대사 후보가 겹쳐도 빈 말풍선이 되지 않는 회귀 검사를 추가했습니다.
- 기존 RLS의 인증 전 월드 조회 차단, 클라이언트 직접 쓰기 금지, 잘못된 비밀번호, 시도 제한, 만료 및 로그아웃 후 접근 차단 검사를 통과합니다.
- 설정 누락 또는 false 플래그가 운영용 화면을 로컬 게임으로 우회시키지 않는지 검사합니다. 공개 키 검사도 false 플래그로 우회할 수 없습니다.

## 검사 안정화

새 혼잣말 검사는 무작위 친구 대화가 끼지 않는 조건에서 스케줄러를 검사하고, 인사/대화는 별도 모델 검사로 검증합니다. 기존 교감 후 이동 검사의 단일 800ms/프레임 판정은 자연스러운 짧은 휴식을 실패로 판단할 수 있어, 기존 이동 검사 도우미로 **15초 안에 실제 5 월드 단위 이상 이동**하는지 확인하도록 바꿨습니다. 교감 종료·보상·하트·표정 검사는 유지합니다. 최종 전체 검사는 순차 실행으로 통과했고, 실패한 초기 실행이나 중단된 병렬 실행을 통과 횟수에 포함하지 않습니다.

## 검증 범위와 운영 적용

클라우드 브라우저 검사는 운영 Supabase와 격리된 실제 서버 핸들러를 사용하며, 원자적 저장/보안은 PostgreSQL 기반 PGlite로 검사합니다. 모바일 검사는 Chromium의 터치/모바일 화면 재현이며 실제 iOS Safari/Android 하드웨어 검증은 별도입니다.

운영 서버의 비밀번호 값과 실제 RLS 적용 상태를 직접 조회하거나 변경하지 않았습니다. 운영 비밀번호 설정 및 서버·화면 배포 완료로 보고하지 않습니다. 개인 계정 기반 강한 인증은 추가하지 않았으며, 기존 공유 비밀번호 + 서버 입장 권한 구조를 유지합니다.

[실제 배포 클릭 순서](CARE_UPDATE.md). 새 SQL, 월드 초기화, 기존 데이터 재가져오기는 필요하지 않습니다.
