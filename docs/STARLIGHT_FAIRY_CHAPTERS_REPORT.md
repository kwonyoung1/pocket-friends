# 별빛 아레나 요정·챕터 업데이트 구현·검증 기록

운영 주소: https://kwonyoung1.github.io/pocket-friends/

[PR/CI 상태 확인](https://github.com/kwonyoung1/pocket-friends/pulls?q=is%3Apr+head%3Acodex%2Farena-fairy-chapters) · [클릭 안내서](STARLIGHT_FAIRY_CHAPTERS_DEPLOY_GUIDE.md)

이 문서는 코드와 로컬 검증 결과입니다. PR 병합, 운영 서버·웹 배포, 실제 공개 버전 확인은 서로 별개이며 Actions 결과로 확인해야 합니다. 로컬 테스트를 운영 반영으로 보고하지 않습니다.

## 1. 마지막 파티

정식 `arena-start` 성공 시 공유 계정 `lastParty`에 IDs, 순서, owner, at를 같은 CAS로 저장합니다. 이벤트도 같은 필드를 사용합니다. 실패·포기·복귀·네트워크 오류 때문에 기존 파티를 지우지 않습니다. 과거 전투 티켓의 편성이 있으면 이를 우선 복원합니다. 보유하지 않은 ID·중복·과원·COST·리더 결여는 안전한 편성으로 보정하고 안내합니다. 임시 편성은 입장 성공 전 서버 값을 덮어쓰지 않습니다.

## 2. 난이도

기존 ID 기준 초반 HP/ATK/DEF 배율은 기존 난이도 함수 대비 약 1.08배, 2~3챕터 1.3배, 고대 유적 1.5배, 기존 후반 챕터 약 1.71배입니다. 심층 6~10단계에는 추가 보정이 있어 10-10은 원래 후반 난이도 기준 약 1.83배입니다. 새 최상위는 약 1.98배입니다. 실제 적 능력치에는 스테이지 레벨과 몬스터 기본값도 반영됩니다.

고대 유적 이후 속도·격파 게이지·결계를 강화하고, 보호막 이후 광역 공격, HP 50% 이하 2단계 약화/공격, 약점 변화 및 제한된 치유를 사용합니다. 다음 행동을 HUD에 예고합니다. 제어 면역·중첩 제한·전투 턴/행동 상한은 유지합니다. 늦은 무한 치유는 제한합니다.

동일 시드 7의 시험에서 훈련/스킬 최대·5성 요정을 포함한 5인 파티가 14개 챕터 최종 보스를 클리어하며, 무강화 1성 구성은 최종 신전에서 패배합니다. 이는 특정 구성의 계산 검증이며 모든 파티·시드의 승리를 보장하는 측정은 아닙니다.

## 3. 경험치

기존 ID의 코인과 입장 에너지는 유지합니다. 일반 탐험·보물 주문서 공식은 변경하지 않습니다.

| 스테이지 | 첫 XP | 반복 XP | 에너지 |
|---|---:|---:|---:|
| 1-1 | 91 | 45 | 10 |
| 3-5 | 268 | 172 | 12 |
| 4-5 | 278 | 179 | 12 |
| 4-10 | 287 | 186 | 12 |
| 10-5 | 822 | 553 | 25 |
| 10-10 | 842 | 568 | 25 |
| 11-10 | 882 | 598 | 25 |

최초·반복 모두 에너지당 XP 효율이 진행 순서대로 상승합니다. 출전한 일반 친구의 아레나 성장·모험가·요정에 각각 지급합니다. 규칙 6의 동료별 일일 상한은 600에서 16,000 XP로 올리고 UI에 표시합니다. 일반 육성 성장에는 지급하지 않습니다. 최고 레벨 50에서는 새 XP가 누적되지 않습니다. 기존 진행 중 규칙 5 전투는 입장 당시 XP와 600 상한을 따릅니다.

## 4. 에너지

주기를 720,000ms에서 360,000ms로 절반으로 줄였습니다. 분수 누적 시간을 유지하며 상한 100, 기존 스테이지 및 이벤트 소비량은 유지합니다. 한국시간 날짜가 저장된 마지막 날짜보다 바뀌면 100으로 정산합니다. 지출은 해당 날짜를 기록하여 같은 날 재접속/다른 기기에서 다시 충전되지 않습니다. 오프라인 여러 날도 상한만 채우며 누적 초과하지 않습니다.

서버 시각으로 계산하고 기존 refresh 또는 아레나 명령의 CAS에서 이력을 저장합니다. 자정 표시·다음 회복 카운트다운은 서버 시각 오프셋으로 갱신하며 초 단위 API나 새 cron을 추가하지 않습니다.

## 5. 챕터·보스

기존 10개 지역과 50개 ID를 보존합니다. 첫 3개 지역은 5단계, 고대 유적~천상의 문은 10단계로 확장합니다. 기존 5단계는 중간 보스, 추가 10단계가 최종 보스입니다. 기존 클리어와 첫 보상 플래그는 유지하고 과거 챕터 접근권만 따로 보존합니다. 신규 클리어 기록을 만들어 내지 않습니다.

신규 지역: 별의 정원, 꿈의 미궁, 천공의 성, 잊혀진 별의 신전. 각 10단계이며 중간 정예 보스와 최종 보스는 다른 몬스터입니다. 총 일반 스테이지 125개(75개 추가), 이벤트 1개 유지, 몬스터 정의 68종(23종 추가)입니다. 챕터별 최종 보스는 14명입니다.

기존 지역 추가 보스: 봉인의 거신, 용암의 심장, 빙관의 수호자, 영야의 늑대왕, 성계의 문지기, 월식의 대군주, 여명의 재판관. 신지역 최종 보스: 별의 정원지기, 악몽의 마법사, 천공의 수호왕, 별의 심판자.

## 6. 명칭·아트·모바일

현재 사용자 화면의 환수/공명을 요정/속성으로 바꾸고 beast/resonance/fusion 및 소유 데이터 ID는 유지합니다. 기존 캐릭터 이름/사진/원화를 바꾸지 않습니다. 과거 전투 표시도 변환하되 사용자 이름 접두어는 유지합니다.

신지역 배경 4개·몬스터 시트 4개는 직접 작성한 경량 SVG이며 총 48,831바이트입니다. 서로 다른 정원·미궁·성·신전 도형을 사용합니다. 원화 생성이나 새 고해상도 픽셀 원화 제작으로 보고하지 않습니다. 몬스터 모션은 4프레임의 작은 움직임입니다. 기존 챕터 추가 보스는 기존 시각 자료를 재사용합니다.

모바일 가로 챕터 선택, 이전/다음, 10단계 목록, 보스/클리어 표시, 마지막 챕터 기억을 제공합니다. 전투는 선택 지역 시트만 불러오고 카운트다운은 네트워크 요청을 발생시키지 않습니다. 새 엔진·외부 패키지는 추가하지 않습니다.

- 360×800, 375×812, 390×844, 412×915에서 UI/터치 확인. 실기기 검증은 아님.
- 전체 TypeScript/프로덕션 빌드 및 단어 정답/이펙트 격리 검사 통과.
- 두 Edge Function frozen-lock Deno 타입 검사 통과.
- 파티 재입장·로그인·다른 기기·이벤트, KST 자정·동시 지출·조작 시간 거부, 최대 레벨, 서버 보상 재현·중복 수령 방지, 125개 클리어 저장 복원, 규칙 5 완전 재현을 검증.
- DB DDL/스키마 변경·운영 DB 데이터 편집·레벨/재화/진행 초기화 없음. 이전 시즌에 아직 진입하지 않았던 계정도 현재 공개 명령은 초기화 없이 이어감.
- 필수 GitHub CI 전체 실행은 위 로컬 범위와 별개이며 성공 조건을 그대로 유지.

## 8. 배포
