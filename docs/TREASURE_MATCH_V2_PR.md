# 보물 3매치 v2: 5초 콤보·무한 도전·강화 이펙트

보물 3매치에서 한 교환의 자동 연쇄와 다음 교환의 직접 콤보를 분리하고, 성공한 교환을 5초 안에 이어 가면 점수 배율이 올라가도록 변경했습니다. 기존 30개 스테이지와 기록을 유지하면서 30초 시작·매치당 +5초·최대 30초의 무한 도전 모드를 추가했습니다.

직접 콤보와 잔여 시간은 입력 가능한 시간만 계산하며 계산·연출·자동 섞기·일시정지 중에는 멈춥니다. 큰 콤보 HUD, 파편·충격파·특수 조합 효과, 보드만 흔들리는 효과와 강도/모션 줄이기 설정을 추가했습니다. 도전 난이도는 단계적으로 오르고 안정 보드는 유효 교환을 최소 두 개 유지합니다. 기존 특수 보석이나 만들어진 매치를 난이도 때문에 초기화하지 않습니다.

도전 최고/최근 기록은 로컬에 추가 저장하며 이전 v1 탭이 열려 있어도 보관합니다. 육성 월드·사진·코인·사천성·영단어·클라우드 서버/SQL은 변경하지 않습니다. 외부 보상은 없고 웹사이트만 배포합니다. 도전은 힌트 없이 진행하며 기존 스테이지 무료 힌트는 유지합니다.

검증: 단위 389개·전체 브라우저 158개·클라우드 48개·실제 5분 실행 2개와 빌드 통과. PC·모바일 rAF 평균 56.12/58.18회·브라우저 오류 0개이며 긴 작업도 관측되었습니다. 100판 반응 시간 모델과 실측의 상세 결과는 [검증 보고서](https://github.com/kwonyoung1/pocket-friends/blob/feat/treasure-match-v2-challenge/docs/TREASURE_MATCH_V2_VERIFICATION.md)를 참고하세요. 시뮬레이션은 실제 사람의 승률 측정이 아닙니다.
