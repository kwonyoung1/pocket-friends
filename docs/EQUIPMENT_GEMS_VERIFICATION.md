기존 테스트 중 “탐험 중 지역 버튼 4개” 기대값은 지역이 7개로 늘어난 결과에 맞춰 7개로 수정했습니다. 가구 중첩을 거절하던 단위 검사는 같은 좌표 중첩을 허용하되 수량이 유지되고 방 밖 이동을 거절하는 검사로 변경했습니다. 기존 전설 보물 풀 검사는 신규 전용 보물이 기존 동굴·정원에 유입되지 않도록 지역 제한을 반영했습니다. 검사를 제거하거나 건너뛰지 않았습니다.

## 검증 환경과 범위

- 단위 검사의 서버 경쟁 테스트는 기존 Supabase SQL을 PGlite의 실제 Postgres에 적용해 기존 RPC로 실행합니다.
- 클라우드 브라우저 검사는 테스트용 인증 및 메모리 저장소와 실제 서버 명령 처리 코드를 사용합니다. 운영 사용자 데이터에는 접근하거나 변경하지 않습니다.
- 로컬·클라우드 브라우저 검사는 desktop 및 모바일 터치 Chromium 프로필에서 실행합니다.
- 개발 중 사용자 Supabase 프로젝트에 코드를 배포하지 않습니다. 실제 운영 배포 후 확인은 배포 안내를 따릅니다.
- 생성된 화면 이미지는 `/tmp/pocket-gear-*.png`에 보관해 육안으로 확인했습니다.

## 최종 실행 결과

| 실행 | 결과 |
|---|---|
| `npm test` | 22개 파일 · 214개 통과 |
| `CI=1 npm run test:e2e -- --workers=2` | PC·모바일 총 122개 통과 · 7.2분 |
| `CI=1 npm run test:cloud -- --workers=2` | PC·모바일 총 42개 통과 · 5.3분 |
| `npm run build` | TypeScript·Vite·정답 데이터 번들 제외 검사 통과 |
| Deno frozen lockfile 검사 | Edge Function 검사 통과 · lockfile 변경 없음 |
| `git diff --check` | 통과 |

새 기능만 먼저 실행한 로컬 브라우저 4개와 클라우드 브라우저 2개도 통과했습니다. 첫 전체 게임 실행은 지역 수 4개를 기대하던 PC·모바일 검사 2개가 실패했고 나머지 120개가 통과했습니다. 기대값을 7개로 수정한 뒤 **전체 122개를 다시 실행해 모두 통과**했습니다.

빌드에는 기존의 500kB 초과 청크 크기 경고가 남습니다. 오류가 아니며 경고를 숨기기 위해 설정을 변경하지 않았습니다. 테스트가 생성한 기존 문서 스크린샷의 시간·랜덤 배치 변경은 커밋에서 제외했습니다.
