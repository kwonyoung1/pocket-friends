# 승인한 A안 동물 원화 적용 — 2026-11-20

사용자의 **“1안으로 진행시켜”** 승인에 따라 봉제인형형 A 원화를 실제
캐릭터 렌더러에 연결했다. 이 문서는 로컬 구현·검증 결과이며, 병합 및 운영
배포 성공을 대신하는 증빙은 아니다.

## 적용 범위와 보존

- 모모(고양이), 비비(토끼), 코코(곰), 두두(여우), 루루(크림 고양이),
  토토(갈색 곰), 별이(라벤더 토끼), 뭉치(강아지), 확장 햄스터의 개별 외형.
- 기존 ID로 외형을 선택하므로 이름을 바꿔도 원화가 유지된다. 기존 kind/color만
  전달하는 입양·목록 UI도 호환한다. 햄스터는 렌더러용 종만 추가했고 저장 형식은 그대로다.
- 영이·찬미 이미지와 HumanSprite, 사용자 사진 처리, 저장/동기화 코드,
  좌표·충돌·경로·성장·경제·사천성·3매치 규칙을 변경하지 않았다.
- 등록 사진은 여전히 원화보다 우선한다. 기존 PNG 및 기존 애니메이션 파일은 보존했다.

## 원화와 애니메이션

`art-source/plush-A/`에는 승인된 개별 기본 원화 9개와 새로 그린 20포즈 시트
9개가 있다. 모두 image_gen으로 제작했으며, 새 포즈는 승인 원화를 참조해
별도로 그렸다. 기존 동물 원화에서 포즈를 추출했다거나 수작업 리깅했다고 주장하지 않는다.
`sources.json`과 `metadata.json`에 생성 방식·원본 해시·런타임 해시·프레임 정보를 기록했다.

- 기본 자세는 승인한 개별 원화를 균일 축소해 사용한다.
- 캐릭터마다 네 발 걷기 8프레임, 생활 12프레임(기본·깜빡임·앉기·수면·기지개·
  그루밍·하품·주변 보기·기쁨·먹기 2장·놀이)을 사용한다.
- 실제 좌표 이동 거리가 보행 프레임을 진행시킨다. 기존 시작·정지·방향 전환
  블렌딩과 드래그 중 정지 처리를 유지했다. 별도 사용자 보상 요청을 만들지 않는다.
- 생활 포즈는 대기 중 15~30초 간격, 눈 깜빡임은 3~7초 간격으로 분산한다.
- 포즈 간에는 짧은 크로스페이드가 있다. 파츠별 연속 리깅은 아니며, 귀·꼬리의
  움직임은 그려진 포즈에 포함된다. 일부 원본 셀 가장자리의 털/수염 픽셀은 메타데이터에
  남겼다. 출력은 프레임 사이 투명 여백과 경계를 검사했다.

원화 검토 단계에서 요청한 외부 레퍼런스 8곳의 열람은 네트워크 403으로 완료하지
못했다. 외부 이미지를 열람·라이선스 확인한 것으로 보고하지 않으며, 외부 에셋을
프로젝트에 포함하지 않았다.

**방 전체의 자율 이동 대기시간·최대 2명 제한·말풍선 정책은 이번 원화 변경에 포함하지
않았다.** 기존 게임 상태 진행을 그대로 사용하며, 이번에 줄인 것은 시각적 생활 포즈의
발생 빈도다. 방 운영 정책까지 변경한 것으로 해석하면 안 된다.

## 모바일 성능

- 런타임 이미지는 256px 프레임의 WebP 27파일, 합계 **2,307,304바이트(2.20MiB)**.
- 기존 5종의 idle PNG + 보행/생활 atlas 합계는 **3,710,699바이트**.
  전체 등록 에셋 용량 비교로 약 **37.8% 감소**했다. 9개 개별 외형과 기존 5종의
  비교이며, 특정 기기의 최초 다운로드량이나 실제 메모리 절감률을 측정한 값은 아니다.
- 작은 목록 아이콘에는 기본 원화만 사용한다. 애니메이션 atlas는 화면에 들어올 때
  디코딩하며, 동일 URL의 디코딩 요청을 공유한다.
- 기존 공유 30Hz 스케줄러, IntersectionObserver, 백그라운드 중단,
  reduced-motion 처리를 사용한다. 별도 Pixi/GSAP 인스턴스를 추가하지 않았다.
- atlas 다운로드가 실패하면 승인된 기본 원화를 계속 표시하며 자동 재시도하지 않는다.
- 이 이미지들은 웹 배포 에셋이다. Supabase 저장 데이터에 이미지 바이너리나 새 필드를
  넣지 않는다. Supabase Egress 절감 수치와 혼동하지 않는다.

## 검증 및 재현

```sh
node scripts/prepare-plush-art.mjs
node scripts/check-plush-art.mjs
npm test -- --maxWorkers=1
npx playwright test tests/plush-animals.spec.ts tests/animals.spec.ts tests/interactions.spec.ts --project=mobile --workers=2
npx playwright test --config playwright.cloud.config.ts cloud-tests/egress.spec.ts cloud-tests/cloud.spec.ts --project=mobile --grep 'unchanged probes|offline commands|free human gifts|two devices share new names'
npm run build
```

원화 검사는 189개 렌더링 프레임의 크기·투명 경계·빈 프레임·8개 보행 프레임의
중복 여부 및 원본/런타임 SHA256을 검사한다. 자동 검사는 미술적 품질 평가를 대체하지 않는다.

로컬 실행 결과:

- 전체 단위 테스트: 단일 워커 실행 **44파일 / 550개 통과**. 최초 기본 병렬 실행은
  549개 통과, 기존 `match3/rewardServer.test.ts`의 동시 보상 재시도 테스트 1개가
  `pending` 상태로 실패했다. 해당 파일 단독 8개 통과 후 전체를 단일 워커로 확인했다.
  보상 코드나 테스트의 제한을 변경하지 않았다.
- 동물/상호작용 모바일 회귀: **12개 통과**(원화 화면·사진·드래그·보상 중복 방지 포함).
- 다운로드 실패 fallback 모바일 검사: **1개 통과**.
- 최초 안내를 이미 읽은 가정 fixture로 화면을 다시 캡처한 최종 원화 전용 검사:
  **3개 통과**(네 화면·사진 우선·다운로드 실패).
- 로컬 클라우드 fixture 모바일: **4개 통과**(기기 간 이름/입양/가구/사진/인물 보존,
  변경 없는 경량 조회, 변경분 동기화, 오프라인 후 동일 작업 ID 복구).
- TypeScript 및 production build: **통과**. 기존 큰 번들 경고는 남아 있다.
- 운영 DB를 테스트 대상으로 사용하지 않았다. 운영 사용자 데이터 보존을 직접 조회했다고
  주장하지 않으며, 보존은 변경 범위와 fixture/로컬 저장 회귀 검사로 확인했다.

## 배포

생략하거나 정책을 변경하지 않는다. 이 변경에는 Edge Function 및 DB 마이그레이션이 없다.
