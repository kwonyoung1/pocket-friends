# feat: add +30 equipment enhancement and retire word minigame

기존20종 장비 개체에+30 강화/목표별 비용/실패 보정을 추가한다. +20까지 코인만, +21부터 강화석을 사용하며 실패 시 단계 유지/파괴 없음이다. 서버 난수와 기존 operation receipt/CAS 트랜잭션으로 차감·결과·이력을 원자적으로 처리한다. 화면은 최종 확률/비용/후속 효과와10/20/30 아우라를 제공한다.

강화석을 동굴 이상에서 기존 추첨 후 독립 보상으로 확정한다. 강화 배율과 시간50%/기본 코인150%/희귀·전설12%p 상한,80/20 확률 배분을 공통 계산에 적용하고 출발 시 결과를 고정한다. 희귀/전설 보물 가격은 원본 카탈로그에서 한 번만20배 적용한다. 원가0인 기존 판매불가 전설3종은 유지한다. 개인/일괄 판매 가격은 동일하고 배치 재고/잔액 상한 검사를 유지한다.

영단어 UI/진입점과 모든 서버 명령 실행을 제거한다. 자동 만료/코인 지급을 중단하고 저장 필드·호환 파서/과거 원본을 보관하여 예전 기록은 삭제하지 않는다. 사천성/보물3매치 제품 소스, 기존 월드·사진·코인·다른 소지품은 보존한다.

검증: 관련 단위127개, PC/모바일 관련 화면12개+사천성4개, 클라우드8개 통과. 중복/응답유실 재시도, SQL 커밋 실패 롤백, 다른 기기/새로고침, 영단어 기록 보존, 기존 보물3매치 정산 포함. 빌드·영단어 정답 묶음 제외·Edge Deno 검사 통과. 전체 장시간 soak는 재실행하지 않음.
