# 보물 3매치 새 이펙트 적용

실제 보물 3매치의 표시 계층에 PixiJS 8.22.0과 GSAP 3.15.1을 적용했습니다. 게임을 열고 이펙트를 ‘강하게’ 또는 ‘보통’으로 설정하면 GPU 이펙트를 사용합니다. 게임 확정 프레임만 읽으며 점수 계산, 이동 판정, 서버 코인 정산, 저장 형식은 변경하지 않습니다.

- 자체 제작 CC0 보석 그림 7색 + 무지개: 일반 호박석은 무지개와 별도의 주황색 그림입니다.
- 드래그 빛 잔상, 탄성 복귀, 파편·발광·충격파, 10개 이상 제거 시 이중 대형 충격파, 실제 특수 보석 대상에 연결하는 광선.
- 10콤보 이상에서 실제 점수와 콤보 숫자의 탄성 강조. 시연용 가상 점수는 사용하지 않습니다.
- PC 최대160/모바일96 파편, 보통60%, 느린 프레임 지속 시64로 축소. 충격파32개 및 광선 표적64개 상한.
- ‘부드럽게’, 감소 모션, WebGL 초기화 실패·컨텍스트 손실 시 기존 Canvas로 전환합니다. Canvas 코드는 CanvasPainter.ts로 이동하고 기존 테스트용 export는 유지했습니다.
- 종료 시 RAF, ResizeObserver, 포인터 이벤트, 텍스처, GSAP 애니메이션을 정리합니다. 이펙트는 입력을 가리지 않습니다.

비교 테스트 페이지는 그대로 남아 있습니다. 기존 성능 보고서는 운영 통합 전의 시제품 측정입니다. 새 엔진이 모든 기기에서 더 빠르다고 보장하지 않습니다. 이번 브라우저 검증은 Chromium의 PC·모바일 에뮬레이션이며 실제 휴대폰의 GPU·발열 성능은 추가 확인이 필요합니다.

## 병합 및 배포

1. https://github.com/kwonyoung1/pocket-friends/compare/main...feat/match3-modern-effects?expand=1 에서 Create pull request를 누릅니다.
2. 자동 검사가 모두 완료되어 초록색인지 확인합니다. 실패 시 병합 전에 해당 로그를 확인합니다.
3. Merge pull request → Confirm merge를 누릅니다.
4. https://github.com/kwonyoung1/pocket-friends/actions/workflows/deploy.yml 에서 main의 새 실행을 엽니다. build와 deploy 모두 초록색이 될 때까지 기다립니다. 수동 Run workflow는 필요 없습니다.
5. https://kwonyoung1.github.io/pocket-friends/ 를 새로 열어 보물 3매치로 들어갑니다. PC에서는 Ctrl+Shift+R로 새로고침하고 모바일에서는 기존 탭을 닫은 뒤 다시 엽니다. 저장 데이터나 사이트 데이터를 삭제하지 마세요.
6. 이펙트 ‘강하게’를 선택해 보석 그림과 폭발을 확인합니다. 기기가 느리면 ‘보통’ 또는 ‘부드럽게’를 선택합니다.

Supabase 함수·SQL·환경변수를 변경하지 않았으므로 Deploy cloud backend (manual)은 실행하지 않습니다. 이전 저장 데이터와 기존 서버를 그대로 사용합니다.

## 라이선스

자체 SVG 및 런타임 파편은 프로젝트 자체 제작입니다. SVG의 CC0 고지는 public/effects-lab/assets/LICENSE.md, PixiJS MIT 및 GSAP Standard 무료 라이선스 고지는 public/effects-lab/licenses에 포함되어 있습니다. Kenney 외부 파일은 사용하지 않았습니다.

## 검증 결과

- 단위 테스트 전체: 34개 파일, 511개 테스트 통과. Canvas 분리 후 관련 이펙트·시제품 단위 테스트도 재검증했습니다.
- 게임 브라우저 검사: PC·모바일 총28개 통과. 연쇄3/5/10, 기존 육성 데이터 유지, 입력·취소, 일시정지, 기록, 난이도12, Canvas 전환, WebGL 컨텍스트 손실, 종료 정리를 확인했습니다.
- 독립 비교 화면 브라우저 검사: PC·모바일 총6개 통과.
- 프로덕션 빌드 및 번들 검사 통과. 거실 초기 정적 의존성에는 PixiJS·GSAP가 없고, 게임 모듈에 비교 시연 코드가 섞이지 않는 것을 자동 검사합니다.
- 전체 장시간 E2E 및 실기기 GPU 성능 측정은 이번 변경에서 다시 실행하지 않았습니다. CI의 전체 검사를 완료한 뒤 병합하세요.
