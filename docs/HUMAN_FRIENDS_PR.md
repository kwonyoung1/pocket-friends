# 남자아이·여자아이를 특별 지급 친구로 추가

남자아이와 여자아이를 고정 ID `special-boy`, `special-girl`로 한 번씩 무료 지급합니다. 일반 친구 8명/유료 입양 4종 한도와 별도로 관리하여 최대 10명이 함께 생활합니다. 기존 사진·이름·육성·지갑·인벤토리·진행 중 탐험을 유지하고, 로컬 원본을 추가 전에 백업합니다. 클라우드 지급은 기존 행 잠금/revision/UUID 영수증으로 중복 생성과 중복 비용을 막습니다.

독립 투명 PNG 두 장, 각 28개 한국어 대사, 자율 이동·교감·놀이·휴식·수면·개명·탐험과 연결했습니다. 첨부 자료는 앉은 커플 장면 한 장이므로 배경 제거와 가려진 옷 윤곽 보완을 거친 이미지 편집 결과입니다. 정확한 측면·후면·보행·누운 수면 프레임은 원본에 없어 추출하지 못했으며 CSS 동작/하트/담요 등으로 대체합니다. 모든 동작에서 얼굴 원화를 유지하고 컨테이너 크기와 바닥 기준점을 고정합니다.

기존 Pages 워크플로는 유지합니다. 새 SQL이나 추가 키 없이 기존 서버를 최신 main으로 수동 재배포해야 새 지급 명령과 ID를 인식합니다. 자세한 클릭 순서는 `docs/HUMAN_FRIENDS.md`에 있습니다. 실제 운영 월드를 이 작업에서 직접 수정하거나 배포하지 않았습니다.

검증: `npm test`, `npm run build`, 고정 잠금 파일을 사용하는 Edge Function Deno 검사, PC/모바일 Playwright, 두 기기 클라우드 Playwright. 실제 PNG 알파/테두리, 새 친구의 상태 전환·독립 조작·데이터 보존·중복 지급을 검사합니다. 최종 실행 수치는 `docs/HUMAN_FRIENDS_VERIFICATION.md`에 기록합니다.
