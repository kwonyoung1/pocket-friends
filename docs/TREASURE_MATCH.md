# 보물 3매치 — 플레이와 구현 안내

메인 화면의 **💎 보물 3매치**를 누르면 독립 퍼즐이 열립니다. 같은 보석을 가로·세로 3개 이상 연결하고 연쇄와 특수 보석으로 목표 점수를 달성하세요. 기존 사천성·영단어와 별개 게임입니다.

[PC 화면](screenshots/treasure-match-desktop.png) · [모바일 화면](screenshots/treasure-match-mobile.png)

## 조작과 기록

- PC: 이웃한 두 칸을 차례로 클릭하거나 마우스로 끕니다. 모바일: 두 칸 터치 또는 상하좌우 스와이프입니다. 키보드는 방향키로 초점을 옮기고 Enter/Space로 두 칸을 선택합니다.
- 성공한 교환이나 특수 조합만 이동 1회를 사용합니다. 매치 없는 교환은 돌아오며 횟수를 쓰지 않습니다. 연쇄가 끝날 때까지 추가 입력을 막습니다.
- **힌트**는 무료입니다. **일시정지/재개**, **다시 시작**, **소리 ON/OFF**, **게임 방법**을 제공합니다. 다른 탭으로 이동하면 자동 일시정지하며, 돌아와 **계속하기**를 누릅니다.
- 최고 점수와 해금 스테이지는 `pocket-friends-treasure-match-v1`이라는 별도 localStorage 키에 저장합니다. 각 스테이지 최고 점수와 효과음 설정도 보관합니다. 새로고침 후 스테이지 선택에서 해금된 곳을 재도전할 수 있습니다.
- 진행 중인 보드는 종료/새로고침 후 새 보드로 시작합니다. 기록은 브라우저별로 보관하며 PC와 모바일 사이에 공유하지 않습니다. 메인 게임의 **추억 보관** 파일은 육성 월드 백업이며 이 별도 퍼즐 기록은 포함하지 않습니다.
- **포켓프렌즈 코인·경험치·아이템·장비·능력치 보상은 없습니다.** 실제 공유 월드와 이 퍼즐의 점수는 별개입니다.

## 특수 보석

| 생성 조건 | 보석 | 효과 |
| --- | --- | --- |
| 4개 일렬 | 가로/세로 관통 | 같은 방향 한 줄 전체 제거 |
| 5개 일렬 | 무지개 | 교환한 보석과 같은 색 전체 제거 |
| ㄱ·T자 등 교차 5개 이상 | 폭발 | 중심 3×3 제거 |
| 같은 색 2×2 | 번개 | 일반 보석을 우선으로 다른 보석 최대 3개 추적 |

같은 그룹에서 무지개 → 폭발 → 관통 → 번개 순서로 한 개를 생성하고, 떨어진 그룹은 각각 생성합니다. 움직인 보석의 도착 위치를 우선하며, 기존 특수 보석을 덮어써 만들지 않습니다. 무지개는 색이 없는 프리즘입니다.

| 교환 조합 | 결과 |
| --- | --- |
| 관통 + 관통 | 도착 위치 기준 가로·세로 십자 |
| 관통 + 폭발 | 도착 위치 기준 3행·3열 |
| 폭발 + 폭발 | 중심 5×5 |
| 무지개 + 일반 | 해당 색 전체 |
| 무지개 + 관통 | 해당 색을 가로·세로 관통으로 전환 후 발동 |
| 무지개 + 폭발 | 해당 색을 폭발로 전환 후 발동 |
| 무지개 + 무지개 | 64칸 전체 제거 후 보충 |
| 번개 + 관통 | 추적한 최대 3곳에서 관통 |
| 번개 + 폭발 | 추적한 최대 3곳에서 3×3 폭발 |

추가로 번개+번개는 최대 6곳을 추적하고, 무지개+번개는 해당 색을 번개로 바꾸어 발동합니다. 특수 조합은 일반 매치 없이도 사용할 수 있습니다.

## 점수·장애물·스테이지

한 제거 단계의 점수는 **(실제로 제거한 보석 수 × 50 + 생성 보너스) × 콤보 배율**이며 정수로 처리합니다. 관통·번개 생성은 +100, 무지개·폭발 생성은 +200입니다. 생성 자리에서 특수 보석으로 남은 보석은 제거 수에서 제외합니다. 여러 폭발이 같은 보석을 맞혀도 한 번만 계산합니다.

콤보 배율은 **×1 → ×1.5 → ×2 → ×3 → ×4 → ×5**이며 6단계 이상은 ×5입니다. 낙하 후 재매치와 다른 특수 보석의 연쇄 발동이 콤보를 올립니다. 새 이동에서는 1단계부터 시작합니다. GOOD/GREAT/AMAZING/FANTASTIC/INCREDIBLE/LEGENDARY COMBO 문구, 위치별 점수 팝업과 큰 점수, 최고 기록 표시를 제공합니다.

얼음 위 보석은 직접 교환할 수 없으며 매치·폭발로 보석을 제거할 때 얼음도 한 겹 손상됩니다. 같은 제거 단계의 겹친 효과로 두 겹이 한꺼번에 사라지지 않습니다. 얼음은 바닥 칸에 남아 다음 보석을 감쌉니다. 성공 조건은 목표 점수이며 모든 얼음 제거를 추가 조건으로 강제하지 않습니다.

| 스테이지 | 색상 | 이동 | 얼음 | 목표 점수 |
| --- | --- | --- | --- | --- |
| 1~5 | 5색 | 25 | 없음 | 2,000 → 5,000 |
| 6~10 | 5색 | 23 | 없음 | 5,800 → 9,000 |
| 11~15 | 6색 | 23 | 없음 | 9,900 → 13,500 |
| 16~20 | 6색 | 21 | 1겹 4칸 | 14,400 → 18,000 |
| 21~25 | 6색 | 20 | 2겹 8칸 | 19,400 → 25,000 |
| 26~30 | 7색 | 20 | 2겹 12칸 | 10,000 → 14,000 |

권장 수치를 그대로 적용한 첫 실험에서는 7색 26~30스테이지를 각각 5회 자동 플레이했을 때 모두 실패했습니다. 색상 증가로 연쇄가 크게 줄어 마지막 구간 목표를 조정했습니다. 마지막 구간의 숫자만 낮아지는 것은 늘어난 색과 얼음에 대한 보정입니다. 30개 스테이지 각각 20개 고정 시드로 재검증한 결과와 한계는 [검증 보고서](TREASURE_MATCH_VERIFICATION.md)에 기록합니다. 자동 플레이의 승률을 실제 사용자 승률로 해석하지 않습니다.

초기 보드는 3개 일렬·2×2 매치가 없고 적어도 한 개의 유효 이동을 가집니다. 이동이 없으면 점수·남은 이동·얼음을 보존해 자동 셔플합니다. 비정상적으로 같은 색 특수 보석만 가득한 경우의 제한된 재생성에서도 특수 보석의 고유 ID와 종류를 보존하며 색은 바뀔 수 있습니다. 무한 반복 방어는 낙하 재매치 최대 64회, 한 폭발 묶음 내 최대 65세대입니다. 도달 시 안정된 보드로 섞어 복귀합니다.

## 그래픽과 성능 구조

루비 육각형, 사파이어 물방울, 에메랄드 직사각 컷, 자수정 수정, 토파즈 마름모, 다이아몬드 브릴리언트, 호박석 타원을 직접 SVG로 제작했습니다. 그라데이션·내부 면·하이라이트·그림자로 입체감을 표현합니다. 7개 SVG 심벌을 재사용하고 그래픽은 메모화해 색/특수 종류가 바뀔 때만 갱신합니다. WebGL 엔진이나 외부 이미지/음원/API를 사용하지 않습니다.

광선·번개·프리즘 연결과 충격파, 보석 파편은 Canvas 2D로 그립니다. 파티클 객체는 128개 풀을 재사용하고 터치 기기는 최대 48개, 느린 프레임이 지속되면 최대 32개로 줄입니다. 그림 크기는 ResizeObserver로 저장하고 프레임마다 레이아웃을 읽지 않습니다. 교환·낙하는 transform, 파괴는 scale/opacity를 사용합니다. 움직임 줄이기에서는 입자·흔들림·광선 애니메이션을 끕니다. 소리는 사용자 입력 후 Web Audio로 합성합니다.

엔진은 보드 계산과 시각 프레임을 분리합니다. 상태는 IDLE/SWAPPING/MATCHING/CLEARING/FALLING/REFILLING/CASCADING을 거쳐 모든 연쇄 완료 후 IDLE로 돌아옵니다. 처리 중 입력은 동기적으로 잠그고 일시정지는 애니메이션 진행 시간까지 보존합니다. Canvas·점수·컨트롤러의 RAF는 필요할 때만 실행하며 종료 시 정리합니다.

## 클라우드와 기존 게임 보존

실제 코드에서 메인 App의 약 80ms 간격 렌더링과 햄스터별 RAF를 확인했습니다. 보물 3매치 진입 중에는 뒤쪽 App/햄스터 그리기와 장식 시계를 쉬게 하고, 메모화한 월드 화면에 전달하는 클라우드 스냅샷을 고정합니다. App을 삭제해 다시 만들지 않아 친구·선택 상태·원래 월드를 유지합니다. 퍼즐 컴포넌트는 별도 상태와 지연 로딩 청크로 실행합니다.

**기존 5초 폴링·Realtime·30초 서버 갱신·대기 중 명령은 계속 동작합니다.** 서버 기준 상태·탐험 시간도 계속 흐릅니다. 퍼즐의 좌표·교환·점수·콤보를 서버에 보내지 않습니다. 종료하면 최신 스냅샷을 방에 전달하고 서버를 한 번 더 조회합니다. 오래된 로컬 월드를 서버에 제출하지 않습니다.

사천성 폴더, 영단어 폴더, CloudClient, 서버 명령/엔진, SQL은 수정하지 않았습니다. 공용 클라우드 흐름의 중단 대신 화면만 격리했습니다. **추가 SQL·테이블·Supabase 서버 배포는 필요 없습니다.** 웹사이트 배포만 진행합니다.

주요 파일:

- `src/match3/engine.ts`, `config.ts`: 순수 보드 규칙·조합·점수·스테이지
- `controller.ts`, `records.ts`: 입력 잠금·일시정지·RAF 진행·독립 기록
- `Panel.tsx`, `GemArt.tsx`, `Effects.tsx`, `styles.css`: UI·SVG 심벌·풀링 Canvas 효과
- `GameShell.tsx`: 지연 로딩·배경 화면 격리·오류 시 거실 복귀
- 수정한 기존 파일: `src/App.tsx`, `src/cloud/CloudGate.tsx`, `src/expansion/UI.tsx`의 새 메뉴/격리 연결
- `tests/fixtures/`: 개발 전용 재현 보드와 측정 도구. 운영 dist에는 포함하지 않습니다.
