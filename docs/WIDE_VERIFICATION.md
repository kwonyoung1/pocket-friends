# 다중 거래·오답 노트·방 확장 검증

기준 main `f8b5764`, 작업 브랜치 `feat/bulk-trade-notebook-expanded-room`입니다. 테스트는 운영 데이터와 분리한 로컬 브라우저·모의 클라우드 API 및 PGlite PostgreSQL에서 수행했습니다. 운영 Supabase에 SQL을 실행하거나 실제 월드를 초기화하지 않았습니다.

## 완료한 검사

- `npm test`: **12개 파일,126개 통과**.
- `npm run build`: TypeScript·Vite 빌드와 운영 JS의 전체 영단어 답안 은행 제외 검사 통과. 기존 번들 크기 안내는 남지만 빌드 오류는 없습니다.
- Deno frozen lock 검사: `deno check --no-config --node-modules-dir=none --lock=supabase/functions/deno.lock --frozen supabase/functions/game/index.ts` 통과.
- `npm run test:e2e`: **82개 통과**, PC·모바일 각41개. 이후 가구 배치 카메라/고정된 배치 도구 보완과 관련한8개를 추가 재검사해 통과했습니다.

- 카메라 외관을 마무리한 뒤 방/가구 배치 관련 **4개 추가 재검사 통과**. 앞선8개와 별도의 마지막 검사입니다.
- `npm run test:cloud`: **26개 통과**, PC·모바일 각13개. 삭제 실패/재시도와 다른 기기 목록 반영까지 실제 UI로 검사했습니다.
- `git diff --check`: 통과.

모든 필수 검사가 통과했습니다. 실제 운영 배포 결과는 아닙니다. 전체 브라우저 검사 뒤 마지막 카메라 조정은 관련 검사로 다시 확인했고, 클라우드26개는 최종 코드로 전체 실행했습니다.

## 검사 중 수정한 사항

첫 전체 브라우저 실행은81개 통과/모바일 입양1개 실패였습니다. 입양 알림의 실제 닫기 버튼이 터치 좌표에 겹친 것으로 확인했습니다. 테스트가 알림을 먼저 닫은 뒤 네 입양 캐릭터를 실제 터치하도록 수정했고, 전체82개가 통과했습니다. 강제 클릭·좌표 조작으로 버튼을 통과시키거나 육성 결과 assertion을 없애지 않았습니다.

확장된 방에서는 기존 배치 도구가 방의 보이지 않는 끝에 있을 수 있어, 방향 버튼으로 카메라를 이동하고 배치 확인·이동·회수 도구는 방 아래에서 조작하도록 보완했습니다. 해당 조작을 새 브라우저 검사에 추가했습니다.

첫 클라우드 전체 실행은25개 통과/모바일 새 검사1개 시간 초과였습니다. 네트워크 실패 안내가 열린 상태에서 그 뒤의 메뉴 닫기를 먼저 누르려던 테스트 순서가 원인이었습니다. 실패 때 오답 목록이 보존되는 것은 확인했으며, 안내의 ‘같은 작업 다시 시도’를 먼저 누르는 실제 복구 흐름으로 수정했습니다. 서버 검증이나 중복 방지 로직을 우회하지 않았습니다.

## 남은 범위와 운영 확인

신규 단어는 난이도별100개, 총300개입니다. 목표 신규1000개/난이도에는900개씩 총2700개가 남았습니다. 직접 작성·검토한 초기 자료이며 외부 사전/전문가 감수·공식 교육과정 검증을 마쳤다고 주장하지 않습니다.

모바일 검사는 Chromium의 iPhone 화면·터치 에뮬레이션입니다. 실제 iPhone Safari/Android Chrome, 운영 Supabase 및 운영 배포는 [안내](WIDE_UPDATE.md)에 따라 확인해야 합니다. 새 SQL 적용·서버 배포·병합·Pages 배포를 수행해야 실제 게임에 반영됩니다.
