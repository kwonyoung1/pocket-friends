# 포근한 거실 업데이트

## 1. 메인 화면

PC는 왼쪽 돌보기 패널과 오른쪽 거실로 정리했습니다. 크림·우드·로즈·세이지 색상, 라운드 카드, 작은 그림자를 사용합니다. 기존 넓은 방 카메라·가구 배치 영역과 충돌 좌표는 유지합니다. 러그를 따뜻한 패브릭 톤으로 바꾸고 벽 가랜드, 일곱 개의 햇살 먼지, 식물의 미세한 흔들림을 추가했습니다. 할로윈 테마도 유지합니다.

## 2. 캐릭터 디자인과 모션

기존 동물 SVG의 부드러운 하이라이트, 반짝이는 눈, 꼬리 움직임과 눈 깜빡임을 보강했습니다. 동물은 기쁨·놀람·배고픔·심심함 등의 눈·입 표현을 바꿉니다. 기존 캐릭터 색상·종류·사용자 사진·이름은 유지합니다.

사람 캐릭터의 기존 PNG와 복장을 보존하고 기존 포즈 연출에 호흡·갸웃·둘러보기·탄성 모션을 덧붙입니다. 이번에는 사람의 새 얼굴 프레임·방향별 이미지나 새 캐릭터 시트를 제작하지 않았습니다. 사람 얼굴 자체의 눈 깜빡임/입 모양을 새로 그린 것은 아니며, 기존 이미지와 모션·이모션으로 표현합니다. 동물의 귀별 독립 관절/손 흔들기 역시 완전한 리깅이 아니라 몸의 작은 움직임으로 표현합니다.

화면에 보이는 깨어 있는 유휴 캐릭터만 3~8초 후 무작위 소동작을 시작하고 1.7초 후 마칩니다. 서로 다른 CSS 호흡 리듬을 가지며, 기존 이동·드래그·수면·상호작용이 우선합니다.

## 3. 인터페이스

선택한 친구의 레벨·친밀도·네 가지 상태를 아이콘·숫자·색 막대로 표시합니다. 낮은 상태는 테두리와 색으로도 구분합니다. 상단에는 한국 시간 시계, 코인, 선택 친구의 친밀도(PC), 실제 추억을 읽는 알림, 화면 설정을 제공합니다. 알림은 기존 추억을 보여 주며 새 서버 알림 시스템을 만들지 않습니다.

## 4. 돌보기와 일괄 관리

먹이·쓰다듬기·씻기·쉬기 버튼을 크게 만들었습니다. 기존 하트·목욕 거품·식사·회복·수면 연출을 유지하고, 상태 이모션과 연결했습니다. ‘모두 돌보기’는 자동으로 여러 명령을 실행하지 않고 기존 일괄 관리 버튼을 펼칩니다. ‘모두 먹이주기’는 인벤토리에서 음식을 선택하고 기존 수량 확인을 거치게 합니다. 보상·쿨타임·음식 소모 규칙은 그대로입니다.

## 5. 상호작용과 이모션

미소, 기쁨, 졸림, 신남, 배고픔, 청결 부족, 외로움/심심함, 만족, 놀람, 휴식의 열 가지 표시 상태를 기존 확정 상태에서 읽습니다. 포만감/청결도 등 30 이하 기준을 유지합니다. 근처의 깨어 있는 친구를 발견하면 웃는 표정과 작은 ‘함께’ 표시를 제공합니다. 이 연출은 좌표·친밀도·경험치·코인이나 저장 형식을 바꾸지 않습니다. 기존 이동·대화 시스템을 유지하며 ‘친구 옆에 새로 앉으러 이동’하는 AI는 추가하지 않았습니다.

## 6. 성능과 접근성

거실에 PixiJS나 GSAP 의존성을 추가하지 않고 CSS·SVG와 적은 수의 타이머만 사용합니다. 무작위 소동작은 화면 밖·백그라운드·감소 모션·이동 중에는 멈춥니다. IntersectionObserver와 타이머를 해제하며, 설정과 OS의 prefers-reduced-motion에 대응합니다. 화면 설정은 이번 접속에만 적용되며 클라우드 데이터에 쓰지 않습니다. 실제 휴대폰 장기 성능/발열은 자동 브라우저 검사로 보장하지 않습니다.

## 7. 파일

- `src/App.tsx`: 메인 레이아웃·상단 도구·일괄 관리 연결
- `src/Character.tsx`, `src/InteractiveFriend.tsx`: 기존 캐릭터에 표현 연결
- `src/Room.tsx`: 기존 배경의 색과 소품
- `src/cozy/presence.ts`, `LivingMotion.tsx`, `RoomAtmosphere.tsx`, `HomeTools.tsx`, `styles.css`: 화면 전용 표현 계층
- `src/cozy/presence.test.ts`, `tests/cozy-home.spec.ts`: 읽기 전용 상태 표현·저장 보존·반응형 검증

Supabase 함수/SQL·게임 상태 계산·미니게임 규칙·재화 처리·저장 마이그레이션은 수정하지 않습니다.

## 8. 검증

단위 테스트 35개 파일·513개 통과, 관련 PC·모바일 브라우저 검사54개 통과, 마지막 모션 최적화 후 새 UI 검사4개 재검증 통과, 빌드·번들 분리 검사 통과했습니다. 클라우드 구매 재시도·사람 친구/사진·음식·휴식의 두 기기 동기화 검사6개도 통과했습니다.

## 9. 모바일

거실을 먼저 보여주고 상태·돌보기는 펼칠 수 있습니다. 돌보기 버튼은 2열, 주요 메뉴는 3열로 정리합니다. 방은 기존대로 좌우로 밀어 둘러볼 수 있습니다. 320px 폭과 가로 화면에서도 가로 문서 넘침이 없는지 검사합니다.

## 10. 병합과 배포

1. [새 PR 만들기](https://github.com/kwonyoung1/pocket-friends/compare/main...feat/cozy-living-room?expand=1) → Create pull request.
2. 자동 검사가 끝나고 모두 초록색이면 Merge pull request → Confirm merge.
3. [웹사이트 Actions](https://github.com/kwonyoung1/pocket-friends/actions/workflows/deploy.yml)에서 main의 가장 위 새 실행을 엽니다. build와 deploy 모두 초록색이 될 때까지 기다립니다.
4. [게임 열기](https://kwonyoung1.github.io/pocket-friends/) → PC는 Ctrl+Shift+R로 새로고침. 휴대폰은 기존 탭을 닫고 새로 열어 확인합니다. 사이트 데이터나 저장 데이터를 삭제하지 마세요.

main 병합으로 자동 배포됩니다. 수동 Run workflow, Deploy cloud backend (manual), SQL 실행은 필요 없습니다. 기존 Supabase 설정과 저장 데이터가 유지됩니다.
