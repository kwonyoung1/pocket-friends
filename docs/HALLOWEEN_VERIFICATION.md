# 할로윈·배치 영역 검증

기준: 2026-10-23, 최신 `origin/main`의 `b70b0ce`에서 만든 `feat/halloween-room-placement`. Node.js 24, 시스템 Chromium, PC 및 iPhone 13 크기/터치 에뮬레이션으로 검사했습니다.

## 검증 범위

- 무료 테마 전환, 반복 전환, 기본 테마 복귀, 로컬 저장·새로고침, 두 기기 간 테마 공유.
- 테마 변경 전후 사진·이름·고정 ID·코인·인벤토리·장비·미니게임 기록·기존 배치 좌표·레이어 보존. 기존 경계를 벗어나는 오래된 화분도 강제로 이동하지 않는지 확인.
- PC/모바일에서 실제 SVG 본체의 경계를 53종 가구·보석 메타데이터와 비교.
- 종류별 상하좌우 경계 허용/거부, 작은 보석과 큰 침대의 허용 범위 차이, 보석 절반 크기.
- 네이티브 터치 입력으로 상단·하단 배치, 미리보기와 저장 좌표, 경계 안의 실제 그림, 레이어 편집·개별 회수·재접속 복원.
- 할로윈에서도 자율 이동·쓰다듬기·시계 표시, 장식의 터치 비간섭, 움직임 줄이기 설정.
- 새 경계에 장애물 가구 배치 후 200회 이동 갱신에서 경로/충돌 안전성 유지.
- PGlite/PostgreSQL 저장 함수와 실제 서버 핸들러로 서버 시각·동시 요청·같은 명령 중복 소비 방지·구형 화면 쓰기 차단 확인.
- 두 브라우저 문맥의 서로 다른 테마 변경과 가장자리 배치가 기존 클라우드 명령 흐름으로 공유되는지 확인. 원래 브라우저의 로컬 데이터가 클라우드 데이터로 덮이지 않는지 확인.

## 확인의 한계와 데이터 처리

클라우드 자동 테스트는 격리된 DB/서버 핸들러와 인증·네트워크 테스트 장치를 사용합니다. 운영 Supabase 월드에 테스트 아이템을 넣거나 실제 사용자 데이터를 수정하지 않았습니다. 실제 서비스에서의 최종 확인은 [배포 안내](HALLOWEEN_DEPLOY.md)의 마지막 단계에서 진행합니다. 모바일은 Chromium 터치 에뮬레이션이며 실제 iPhone Safari에서 직접 실행한 결과로 표시하지 않습니다.

중간에 두 전체 브라우저 검사를 동시에 실행했을 때 기존 대규모 방 검사 하나가 60초 제한을 넘었습니다. 동시 실행을 중단하고 CI와 같은 순서로 다시 실행하여 위의 전체 130개·44개 통과를 확인했습니다. 검증 기준이나 제한 시간을 늘리지는 않았습니다.

기존 큰 번들에 대한 Vite 크기 경고는 남아 있으나 빌드를 막는 오류는 없습니다. 새 의존성·원격 이미지·유료 API는 추가하지 않았습니다. GitHub Pages와 기존 서버 배포 워크플로 설정을 유지했습니다.

필수 기능은 구현했으며 별도 SQL·DB 초기화는 필요 없습니다. 선택사항인 할로윈 전용 대사는 기존 대사 정책을 유지하기 위해 추가하지 않았습니다.
