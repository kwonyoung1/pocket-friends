# 생활·탐험·가구·새 식구 확장 및 기존 데이터 보존

기존 공유 월드에는 성장·기본 탐험만 있어 생활·방 꾸미기·캐릭터 확장 요청을 사용할 수 없었습니다. 보유한 음식으로 먹이 주기, 30분 목욕/KST 수면/168시간 개명, 지역별 확률과 32종 SVG 수집 가구 배치, 감기약 인벤토리, 새 친구 네 마리 입양과 희귀 햄스터를 추가합니다. 기존 네 친구·사진·코인·성장·아이템·진행 중 탐험 결과를 그대로 읽습니다.

클라우드는 기존 revision/행 잠금/UUID 영수증을 유지하고 첫 확장 저장과 원본 백업을 같은 트랜잭션에서 수행합니다. SQL 미적용 시 확장 저장을 중단하며, 구형 클라이언트에는 새로고침을 안내합니다. 두 기기의 동시 입양·목욕·가구 소비가 중복 결제/보상을 만들지 않는지 PostgreSQL에서 검증합니다.

배포 전 `supabase/migrations/202610150002_life_backup.sql`을 기존 프로젝트 SQL Editor에서 실행해야 합니다. 병합 후 `Deploy cloud backend (manual)`을 main으로 실행하고 Pages 검사/배포 성공을 확인합니다. 기존 프로젝트·비밀번호·월드를 새로 만들지 않습니다. 상세 버튼 순서는 `docs/LIFE_EXPANSION.md`에 있습니다.

`npm test` 67개, PC/모바일 `test:e2e` 52개, 두 기기 `test:cloud` 14개가 통과했고 TypeScript/Vite 빌드와 Deno 잠금 파일 검사도 통과했습니다. 검증 결과는 `docs/EXPANSION_VERIFICATION.md`를 참고하세요. 실제 모바일 기기와 운영 Supabase에서 새 버전 최종 확인은 배포 후 필요합니다.
