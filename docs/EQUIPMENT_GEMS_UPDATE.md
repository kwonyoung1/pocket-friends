# 탐험·장비·보석·가구 업데이트

새 탐험 지역 3개, 전용 수집품 9종, 장비 20종, 보석 배치와 가구 중첩·레이어 편집을 추가했습니다. 기존 클라우드 프로젝트와 JSON 저장 데이터를 사용하며 초기화하지 않습니다.

## 실제 지역 설정

| 지역 | 해금 | 기본 시간 | 기본 코인 | 체력 | 일반 / 고급 / 희귀 / 전설 보물 |
|---|---:|---:|---:|---:|---|
| 신비의 숲 (기존) | 1 | 30분 | 120 | 15 | 70 / 24 / 6 / 0% |
| 반짝이는 해변 (기존) | 5 | 60분 | 240 | 25 | 55 / 32 / 13 / 0% |
| 고대 동굴 (기존) | 10 | 120분 | 500 | 40 | 40 / 37 / 22.75 / 0.25% |
| 비밀의 정원 (기존) | 15 | 240분 | 900 | 55 | 25 / 40 / 34.5 / 0.5% |
| 수정 광산 | 20 | 300분 | 1,100 | 60 | 18 / 42 / 39 / 1% |
| 잊혀진 신전 | 25 | 360분 | 1,400 | 65 | 10 / 37 / 51 / 2% |
| 별빛 성역 | 30 | 420분 | 1,800 | 70 | 5 / 30 / 61 / 4% |

기존 최상위가 Lv.15이므로 +5/+10/+15인 Lv.20/25/30입니다. 기존 정원이 240분이어서 요청서의 권장 60/90/120분 대신, 상위 지역일수록 길어야 한다는 조건에 따라 300/360/420분을 선택했습니다. 기존 네 지역은 변경하지 않았습니다. 활발형 시간 보정, 차분형 체력 절약, 모험가형 경험치 보너스, 호기심형 추가 보물 추첨도 유지합니다.

## 신규 전용 보물

각 아이템은 해당 지역에서만 등장합니다. 새로운 전설 보물도 기존 동굴·정원이나 다른 신규 지역에서는 나오지 않습니다. 기존 공유 보물 풀은 그대로 유지합니다.

## 장비 획득 확률

| 지역 | 장비 획득 | 획득 성공 시 일반 / 고급 / 희귀 / 전설 |
|---|---:|---|
| 숲·해변 | 없음 | — |
| 동굴 | 8% | 55 / 32 / 12.5 / 0.5% |
| 정원 | 10% | 45 / 35 / 19 / 1% |
| 광산 | 12% | 35 / 40 / 23 / 2% |
| 신전 | 15% | 25 / 40 / 31 / 4% |
| 성역 | 18% | 15 / 35 / 42 / 8% |

장비 획득 여부를 먼저 추첨하고 성공 시 등급을 추첨합니다. 예를 들어 동굴의 전설 장비는 8% × 0.5% = 0.04%입니다. 보물 등급·가구·이벤트 추첨과 별개이며 장비는 해당 지역 전용 목록에서만 나옵니다. 같은 종류도 매번 서로 다른 개체 ID를 받습니다.

| 지역 | 일반 | 고급 | 희귀 | 전설 |
|---|---|---|---|---|
| 동굴 | 낡은 광부 모자 · 머리 · 시간 -3% | 광부의 장갑 · 몸 · 시간 -10% | 고대 탐험가의 곡괭이 · 장신구 · 코인 +20% | 지하왕의 투구 · 머리 · 시간 -15% |
| 정원 | 풀잎 모자 · 머리 · 코인 +5% | 요정의 망토 · 몸 · 시간 -8% | 정령의 목걸이 · 장신구 · 코인 +25% | 정령왕의 반지 · 장신구 · 코인 +50% |
| 광산 | 수정 광부모 · 머리 · 시간 -5% | 수정 갑옷 · 몸 · 코인 +12% | 수정 나침반 · 장신구 · 희귀 +3%p | 수정왕의 왕관 · 머리 · 희귀 +6%p |

| 성역 | 별빛 머리장식 · 머리 · 코인 +10% | 달빛 로브 · 몸 · 시간 -12% | 은하의 목걸이 · 장신구 · 코인 +30% | 별의 왕관 · 머리 · 코인 +50% |

### 착용하는 방법

1. 게임의 **캐릭터 성장** → 위쪽 **함께할 친구**에서 캐릭터 선택 → **장비** 탭을 누릅니다.
2. 보유 장비 카드의 **착용**을 누릅니다. 머리·몸·장신구 슬롯마다 하나씩 착용합니다.
3. 교체하려면 해당 슬롯에서 **해제** 후 다른 장비를 착용합니다.
4. 다른 친구에게 줄 때도 먼저 해제하고 친구 선택을 바꿔 착용합니다.
5. **인벤토리 → 장비**와 **생활·입양 → 장비**에서도 관리할 수 있습니다.

회색/파란색/보라색/금색 테두리와 전설 장비의 약한 빛을 표시합니다. 착용 캐릭터 이름도 표시합니다. 이번에는 캐릭터 원본 이미지 위에 옷을 합성하지 않으며, 장비는 슬롯 UI와 효과로 표현합니다. 강화·판매는 요청 범위대로 제공하지 않습니다. 일괄 판매 대상에도 포함되지 않습니다. 처음에는 장비가 없으며, 기존 탐험 완료 보상에 장비를 소급 추가하지 않습니다.

### 효과 계산과 출발 확정

- 장비 시간 감소율을 더해 최대 35%. 기존 활발형 5% 보정도 적용하되 **최종 시간은 지역 기본 시간의 최소 65%**를 유지합니다. 밀리초로 반올림해 저장합니다.
- 코인 증가율을 더해 최대 +80%. `floor(지역 기본 코인 × (1 + 증가율))`이며 탐험 이벤트 추가 코인과 보물 판매가는 배율 대상이 아닙니다.
- 희귀 증가 %p를 더해 최대 +8%p. 일반/고급에서 원래 비율대로 차감하고 희귀에 더합니다. 전설 확률은 고정하며 합계는 100%입니다.
- 출발 시 착용 개체 ID, 합산 효과, 소요 시간, 코인·보물·장비 결과를 서버에서 확정합니다. 도중 장비를 해제하거나 다른 캐릭터로 옮겨도 기존 탐험은 바뀌지 않습니다.

## 보석 배치와 가구 편집

배치 가능한 보석은 코드의 명시적 목록으로 관리합니다. 기존 진주·토파즈·은·자수정·금·루비·사파이어·에메랄드·다이아몬드, 분홍 진주·맑은 수정·숲의 보석, 광산의 신규 세 수집품과 성역의 신규 세 수집품이 대상입니다. 신전 유물·문장·석판, 씨앗 등은 수집품으로 유지합니다.

1. **인벤토리 → 보물**에서 보유 보석 카드의 **방에 배치하기**를 누릅니다.
2. 반투명 배치 영역에서 바닥을 누르거나 손가락/마우스로 위치를 고릅니다. 실제 크기 미리보기를 확인합니다.
3. **여기에 놓기**를 누릅니다. 겹쳐 놓을 수 있으며, 한 개 배치할 때 자유 인벤토리 수량이 한 개 줄어듭니다.
4. **가구 편집 → 배치 아이템 선택** 목록에서 겹친 물건을 개별 선택합니다. 같은 종류도 ID 앞부분으로 구분합니다.
5. **이동하기 / 회수하기 / 맨 앞으로 가져오기 / 맨 뒤로 보내기 / 한 단계 앞으로 / 한 단계 뒤로**를 사용할 수 있습니다.
6. 회수하면 다시 판매 가능한 수량이 돌아옵니다. 회수·판매와 무관하게 발견 도감 기록은 유지됩니다.

보석은 일반 가구의 가로·세로 각각 50%인 4.25%/8% 크기이며 작은 화면에서 최소 26px를 확보합니다. 배치 미리보기도 같은 크기입니다. 전설 보석은 종류별 색의 은은한 아우라와 반짝이를 표시합니다. CSS 기반이며 `prefers-reduced-motion`에서는 애니메이션을 끕니다.

가구끼리도 같은 좌표에 배치할 수 있습니다. 보석과 작은 장식은 캐릭터의 장애물 목록에서 제외하고, 일반 가구의 충돌 영역은 각각 유지합니다. 겹치는 영역은 길 찾기의 합집합으로 작동합니다. 방 밖 배치는 거절하고, 장애물 가구는 산책할 공간·연결 통로도 확인합니다. 기존 최대 배치 개수 18개는 유지합니다. 기존 배치의 ID·좌표·종류·선택적 크기는 보존하며, 레이어가 없으면 기존 목록 순서를 기본으로 사용합니다.

## 저장과 배포

추가 필드는 기존 JSON 내부의 `world.equipment`, 탐험의 `equipmentBonus`·`equippedIds`·장비 보상, 배치의 `layer`·`collision`입니다. 기존 값이나 진행 중인 탐험을 다시 만들지 않습니다. 보석 배치·회수는 기존 수량 이동 방식을 사용합니다.

서버에서 수량·소유·슬롯을 검증합니다. 기존 작업 번호 영속 큐, 중복 요청 영수증, Postgres 잠금과 CAS 재시도로 동시 입력도 처리합니다. 신규 버전이 사용된 월드는 이전 클라이언트의 새 쓰기를 거절해 오래 열린 화면이 새 데이터를 덮어쓰지 못하게 합니다.

**Supabase SQL 추가 실행, 새 프로젝트 생성, 비밀번호·토큰 교체는 필요 없습니다.** 기존 테이블의 JSON과 기존 RPC를 그대로 사용합니다. 이번에는 서버 기능도 변경했으므로 **서버와 웹사이트 둘 다 배포해야 합니다.** 자세한 클릭 순서는 [배포 안내](EQUIPMENT_GEMS_DEPLOY.md)에 있습니다.
