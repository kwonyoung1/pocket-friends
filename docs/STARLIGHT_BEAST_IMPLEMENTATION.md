# 별빛 환수 업데이트 구현·검증 기록

기준: main `fc15a72`(PR #40 병합), 작업 브랜치 `codex/starlight-beast-update`. 2026-11-23.

## 구현

- 실제 친구 10명의 ID·이름·레벨·기존 스킬·마스터리를 유지합니다. 아레나 전용 환수는 `beasts.ts`와 `world.arena.accounts[인증 사용자 ID]`의 별도 타입으로 관리합니다. 일반 `friends[]`에 삽입하지 않습니다.
- 최대 5명·COST10·영이/찬미 필수·중복 금지를 클라이언트와 서버에서 검사합니다. 기존 지휘력 강화 시스템은 main에 없으므로 이를 구현됐다고 보고하지 않습니다.
- 루미/네뷸라 희귀 COST2, 셀레나/폴라/피닉 영웅 COST3, 아스트라/이클립스 전설 COST4, 세라피아 신화 COST5. 역할·공격·투사체·치유·반격·격파·회피 감소·분신·조건부 자기 회복이 구분됩니다.
- 환수는 실제 전투 XP 또는 전용 중복 조각으로 Lv.50까지 성장합니다. 별자리 5단계는 환수 전용입니다. 일반 친구의 기존 마스터리 해금·효과는 바꾸지 않습니다. 현재 착용 장비 강화 합계는 최대12% 아레나 능력치 보조로 시작 시 고정합니다. 편성 카드와 전투가 같은 능력치 계산을 사용합니다. 장비·탐험 보너스 자체는 변경하지 않습니다.
- 기존 40개 스테이지 ID·지역·해금 순서를 유지합니다. 후반 적은 기존 대비 HP 최대1.9배·ATK1.7배·DEF1.55배·SPD+6·약점 게이지+3, 중반부터 정예/보스 결계, 후반 치유 AI·35% 체력 이하 보스 격노 패턴이 추가됩니다. 성장한 일반 친구만으로 최종 보스 승리 가능한 조합을 검증합니다.
- 반복 코인6/9/15/24/36/54/78/120, 첫 코인3배, 승리 상자1개·첫 보스2개. 에너지10/12/15/18/20이므로 후반 에너지당 코인도 증가합니다. 기존 탐험은 그대로이며, 아레나의 자연회복 에너지당 기대 수입이 탐험을 대체하지 않도록 제한했습니다.
- 에너지 최대100·12분당1·서버 시간·계정별. 입장 티켓/차감/명령 영수증을 기존 CAS로 함께 커밋합니다. 실패한 입장 거래는 차감하지 않습니다. 응답만 유실된 시작은 같은 티켓으로 재개하며 재차감하지 않습니다. 패배·포기·만료는 환급하지 않습니다. 코인 충전은 없습니다. 연습은 무소모·무보상입니다.
- 상자6종의 확률 합계는 각10000분율로100%입니다. 서버 crypto RNG로만 추첨하고 공개 전투 시드를 재사용하지 않습니다. 최상급 표65/24/8/2.7/.3%, 신화는 전설 상자만. 전설 이상40회(별빛/전설 합산)·신화300회(전설만) 천장과 실제 보장 확률을 표시합니다.
- 신규·중복 연출 분리, 조각8/16/32/64개, 개봉 nonce·기존 명령 영수증·CAS로 재전송/동시 요청을 보호합니다. 마지막 결과를 재표시해도 재추첨하지 않습니다.
- 익명 로그아웃 후 새 인증 ID가 발급되는 기존 구조를 고려해 256비트 기기 연결 코드를 추가했습니다. 첫 정식 작업 전 기존 내구성 큐로 등록하고, 재로그인 후 자동 재연결합니다. 다른 기기는 비밀번호 로그인과 연결 코드 둘 다 필요합니다. 서버가 비밀값을 SHA-256으로 변환한 뒤 원자 명령/영수증에 전달하며, 공개 해시를 원문으로 재전송해 계정을 가져갈 수 없습니다. 기존 JWT 로그아웃·회원 권한·RLS는 유지합니다. 진행한 계정끼리 자동 합치기/삭제는 거부합니다.
- 기존 공유 클리어 기록은 첫 계정 생성 시 복사해 보존하고, 새 클리어·에너지·환수·천장은 인증 계정별로 관리합니다. 기존 v1 진행 티켓은 `legacy/`에 고정한 계산/기존20코인 등 보상으로 끝까지 정산할 수 있습니다. v2 티켓에만 새 난이도·에너지·상자를 적용합니다. 이전 화면은 업데이트 안내로 보호하며 저장소 삭제를 요구하지 않습니다.
- 선택적 JSON 필드를 사용하며 SQL 스키마·RLS·인증·기존 운영 DB 데이터를 변경하지 않습니다. 아레나 계정32개·기기 연결256개/공유 월드, 진행 티켓16개/6시간/160행동, 상자 종류별9999개, 조각999999개로 크기를 제한합니다. 기록이 가득 찼다고 계정·데이터를 자동 삭제하지 않습니다. 공유 월드 아레나 코인 안전 한도는 한국 시간 하루5000, 계정별 출전 캐릭터 XP 하루100입니다.
- 거래는 시작·웨이브/중단 체크포인트·완료·상자·육성 시에만 보냅니다. 매 공격·애니메이션·에너지 표시 갱신마다 API를 부르지 않습니다. 기존 revision/delta/인증 캐시를 유지합니다.

## 그래픽

image_gen으로 독립 원화8장과 별도20포즈 픽셀 아틀라스8개(160포즈)를 제작했습니다. 런타임 원화/아틀라스와 SHA는 `src/arena/art/beast-metadata.json`, 실제 원본은 `art-source/arena-beasts/`입니다. 기존 친구 원화는 보존했습니다. 네발 동물·두발 새·부유 정령의 몸과 발 수, 투명 배경, 런타임 추출 셀을 시각 검토했습니다.

PixiJS 전투에는 성운 고리·용의 별자리 포격·불사조 깃털·월식 분신·천상 방패 등 독립 효과와 카메라 구도를 추가했습니다. 5인 전열/후열과 후열 공격 이동 우회 경로, 5칸 HUD를 적용했습니다. 획득 장면은 등급별 빛/원/실루엣/원화 공개와 신화 성역·연결 별자리·12개 한도의 CSS 원근 입자를 사용합니다. 연출 건너뛰기와 모션 감소를 지원합니다. 3D 모델이나 골격 애니메이션으로 보고하지 않습니다.

## 실제 참고 자료와 적용 범위

공식 사이트 3곳은 프록시 CONNECT403으로 접근되지 않았습니다. 대신 Git으로 아래 공개 **비공식 커뮤니티 자료**를 실제 읽었습니다. 공식 최신 사양이나 게임 플레이를 직접 검증했다는 뜻은 아닙니다. 자료의 코드·이미지·캐릭터·수치표는 프로젝트에 복사하지 않았습니다.

## 검증과 운영 상태

- 최종 전체 Vitest 검증 **51개 파일·602개 통과**. 편성 카드/장비 보너스 일치 검사도 포함합니다. 아레나 최신46개 통과에는 신규 환수·에너지·확률 경계·천장·중복·부정 입력·레거시 정산·일반5인 최종 보스 공략·장비 카드 일치 검사가 포함됩니다.
- 서버 HTTP CAS/영수증 검사에서 동시 입장1회 차감, 동시 개봉/응답 유실의 신화1회 지급, 타인 티켓 차단, 공개 복구 해시 재전송 공격 차단, 오래된 클라이언트의 첫 입장 무차감 차단을 확인했습니다.
- Deno2.9.6 frozen lock으로 game/treasure 검사 통과, 빌드 및 단어 정답 제외·효과 격리·첫 거실 Pixi/GSAP 제외 검사 통과.
- 기존 모바일 아레나7개 통과. 4개 요청 해상도의5인 배치·0에너지 차단/다른 게임 이용·서버 보상/재접속·신화 신규/중복/연결 복구를 검증했습니다. 최종 프로덕션 빌드 모바일 **11개 통과**: 4개 해상도·정식/연습·보상/재접속·신화·익명 재로그인 자동 복구·다른 인증 기기 연결까지 확인했습니다.
- 테스트는 로컬 인메모리 서버와 공개 fixture 키를 사용합니다. 운영 DB를 초기화·수정하거나 실제 환수/재화를 지급하지 않았습니다. 모바일은 Chromium 터치 에뮬레이션이며 물리 Android/iOS 측정이 아닙니다.
- GitHub API 및 운영 사이트 HTTPS는 이 실행 환경의 프록시403으로 막혀 있습니다. Git 전송/PR 확인과 원격 CI·병합·서버/웹 SHA 확인을 구분해 보고합니다. 성공을 확인하기 전 운영 완료로 선언하지 않습니다. 보호 대상 리뷰/배포 승인 정책을 유지합니다.
