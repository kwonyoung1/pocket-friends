# 탐험·음식·영단어 업데이트 검증

대상: `feat/treasures-food-word-expedition` (기준 main `952dcd9`). 운영 Supabase의 데이터·비밀번호·설정은 변경하지 않았습니다. 로컬 모드 브라우저와 모의 클라우드 API, PGlite에서 SQL/RLS/동시 요청을 검증합니다.

## 완료된 검사

- `npm test`: 10개 파일, **114개 통과**. 기존87개와 새 보물·음식·휴식/영단어/실제 SQL 검사를 포함합니다.
- `npm run build`: TypeScript와 Vite 빌드 통과. 배포용 JS에 전체 단어 답안 은행이 들어 있지 않은지 자동 검사도 통과했습니다. 기존 큰 번들 안내는 남아 있으나 빌드 오류는 없습니다.
- `deno check --no-config --node-modules-dir=none --lock=supabase/functions/deno.lock --frozen supabase/functions/game/index.ts`: 통과.

- `npm run test:e2e`: **76개 통과**, PC·모바일 각38개. 팝업 겹침 수정 후 전체를 다시 실행했습니다.
- `npm run test:e2e -- tests/word-expedition.spec.ts`: 영단어 가독성·다음 문제 안내를 마무리한 뒤 관련 **2개 재검사 통과**.
- `npm run test:cloud`: **24개 통과**, PC·모바일 각12개. 기존20개+신규 기기 간 영단어/음식·휴식4개를 포함합니다.
- `git diff --check`: 통과.

모든 필수 검사가 통과했습니다. 실패 테스트를 건너뛰거나 재시도 횟수를 늘려 가리지 않았습니다. 마지막 화면 수정은 영단어 관련 브라우저2개를 다시 실행해 확인했습니다.

## 브라우저로 진행하는 검사

새 영단어 테스트는 PC·모바일 각각 **30문제를 끝까지** 풀며 정답/오답/정답 보기/건너뛰기/Enter/힌트/다음 문제/3스테이지 이동을 실제 UI에서 실행합니다. 중간 새로고침 후 이어가서27정답·3오답=270코인, 완료 후 새로고침 시 중복 지급 없음, 오답3개 무보상 복습을 확인합니다.

모의 클라우드 테스트도 PC에서 시작한30문제를 모바일 컨텍스트에서 이어 풀고, 중간 새로고침 후 완료하여300코인을 한 번 받는지 확인합니다. 선호 음식과4시간 수동 휴식 제한은 별도 두 기기에서 공유되는지 검사합니다. 원래 로컬 JSON은 변하지 않아야 합니다.

첫 전체 브라우저 실행에서는75개 통과/1개 실패였습니다. 원인은 기존 가구 편집 버튼의 z-index가 입양 팝업보다 높아 클릭을 가로챈 것이었습니다. `.room`에 쌓임 범위를 만들어 방 안 요소를 팝업 아래로 제한했으며, 실패했던 입양 조작이 PC·모바일에서 모두 통과하는 것을 확인했습니다. 테스트 강제 클릭이나 assertion 삭제로 우회하지 않았습니다.
