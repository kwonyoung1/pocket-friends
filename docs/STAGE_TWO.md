# 포켓프렌즈 2단계 · 성장과 작은 모험

기준 코드는 `main`의 PR #2 병합 커밋 `7641e6f`입니다. 기존 교감·이동 코드를 유지하고 `feat/stage-two-progression`에서 확장했습니다. 기존 GitHub Pages 주소와 배포 워크플로를 유지합니다.

## 플레이 순서

1. 화면 상단 **일일 미션** → **출석 30코인 받기**로 오늘의 선물을 받습니다.
2. **상점**에서 **일반 간식**이나 **작은 공**의 **구매하기**를 누릅니다. 현재 잔액은 화면 맨 위에 표시됩니다.
3. **인벤토리** → **함께할 친구**를 선택하고 **친구에게 주기/놀이**를 누릅니다. 음식은 1개씩 소모하고 장난감은 재사용합니다.
4. **캐릭터 성장**에서 네 친구의 레벨·경험치·대표 성격·성격 수치·상태·누적 탐험·희귀 발견을 비교합니다.
5. **탐험** → 친구와 지역 선택 → **탐험 보내기**를 누릅니다. 집에서는 외출 상태가 되며 나머지 친구들은 계속 활동합니다. 창을 닫아도 진행됩니다.
6. 시간이 끝나면 자동으로 귀환·보상을 처리합니다. **수집 도감**에서 보물과 첫 발견 시각을 확인합니다.
7. **일일 미션**에서 진행률을 확인하고, 경험치를 줄 친구를 선택한 다음 **보상 받기**를 누릅니다.

## 성장과 성격

최대 레벨은 50입니다. 현재 레벨 L의 다음 레벨 필요 경험치는 기본 `20 + 10 × L`입니다. Lv.50에서는 잔여 경험치를 0으로 고정합니다. 레벨업 시 이미지·이름·육성 수치는 유지하고 축하 효과와 이벤트 대사를 보여줍니다.

| 행동 | 경험치 | 보상 간격 |
| --- | ---: | --- |
| 음식 주기(기존 먹이 버튼 포함) | 3 | 친구별 10초 |
| 장난감 놀이 | 5 | 친구별 30초 |
| 일반 쓰다듬기 | 1 | 일반/특별 공유 10초 |
| 특별 쓰다듬기 | 3 | 일반/특별 공유 10초 |
| 탐험 | 지역별 20/40/60 | 출발 시 확정, 귀환 시 1회 |
| 미션 | 10/20/30 | 한국 날짜별 미션당 1회 |

경험치가 지급된 행동만 미션에 집계됩니다. 기존 먹이 버튼은 기존 상태 회복 동작을 유지하지만 짧게 반복해도 경험치와 미션을 중복 획득하지 못합니다. 음식 아이템도 먹이 경험치 간격을 공유합니다.

성격은 0~100이며, 보상받은 먹이는 차분함, 놀이는 활발함, 쓰다듬기는 애교, 탐험 출발은 모험심, 탐험 귀환은 호기심에 영향을 줍니다. 성격 변화는 친구별로 1분에 최대 0.25입니다. 가장 높은 수치를 대표 성격으로 정하고 동률이면 정해진 순서로 선택합니다.

| 대표 성격 | 보너스 |
| --- | --- |
| 활발형 | 탐험 시간 5% 감소 |
| 차분형 | 탐험 시작 체력 20% 절약 |
| 호기심형 | 8% 확률로 추가 아이템 1회 추첨 |
| 모험가형 | 탐험 경험치 10% 증가 |
| 애교형 | 친구와 인사할 때 친밀도 추가 +1 |

성격 수치는 친구 접근·가구 방문·휴식 확률과 성격 대사·특별 행동 빈도에도 영향을 줍니다. 상점 잠금은 우리 집에서 가장 높은 친구 레벨을 기준으로 하고, 탐험 잠금은 선택한 친구의 레벨을 기준으로 합니다.

## 경제와 아이템

처음 한 번 300코인을 지급합니다. 기존 v1 사용자도 새 경제 데이터가 없을 때만 받으며, 잔액이 0이 되어도 새로고침으로 다시 지급하지 않습니다. 구매·판매·출석·미션·업적·탐험 내역은 잔액과 함께 최근 100건을 저장합니다.

상점에는 요청한 9종의 음식·놀이·장식품이 있습니다. 구매/판매는 0.8초 간격으로 처리하고 잔액과 수량을 검사합니다. 판매 가격은 설정 가격의 절반입니다. 전설 보물은 판매할 수 없습니다. 게임 코인만 사용하며 현금 결제는 없습니다.

음식은 한 번 사용할 때 1개 소모합니다. 장난감은 재사용하며 놀이 사이 30초 간격을 둡니다. 장식품은 보관 및 향후 배치 슬롯 데이터만 준비하고, 사용 버튼에 **방 꾸미기 준비 중**을 표시합니다. 탐험 보물은 사용하지 않는 수집용이며, 판매 후에도 도감과 발견 날짜는 남습니다.

## 현실 시간 탐험

| 지역 | 필요 레벨 | 기본 시간 | 코인 | 경험치 | 기본 체력 |
| --- | ---: | --- | ---: | ---: | ---: |
| 신비의 숲 | 1 | 30분 | 120 | 20 | 15 |
| 반짝이는 해변 | 5 | 60분 | 240 | 40 | 25 |
| 고대 동굴 | 10 | 120분 | 500 | 60 | 40 |

체력은 출발할 때 소모합니다. 친구마다 동시에 하나의 탐험에만 참여할 수 있으며 다른 친구들은 각각 탐험하거나 집에서 활동할 수 있습니다. 출발 시 종료 시각·코인·경험치·아이템 결과를 전부 확정해 저장합니다. 재접속해도 재추첨하지 않으며 `claimedAt`으로 귀환 지급을 한 번만 처리합니다. 돌아오기 전에는 먹이·쓰다듬기·아이템 사용·드래그를 할 수 없습니다.

아이템 추첨은 **등급 결정 → 해당 지역/등급 아이템 선택**으로 나눕니다. 기본 추첨 1회의 확률은 일반 65%, 고급 25%, 희귀 9%, 전설 1%입니다. 호기심형의 추가 추첨도 같은 등급 확률을 사용합니다. 추가 추첨이 있는 경우 전체 여행에서 전설을 한 번 이상 만날 확률은 1회 추첨의 1%와 다르며, 화면에 추가 추첨 조건을 따로 안내합니다. 확률·보너스는 설정 파일에 있으며 숨겨진 확률 보정은 없습니다.

전설은 황금빛 알림, 축하 대사, 도감, 캐릭터별 발견 수, 획득 시각과 함께 저장합니다. 알림을 닫아도 **수집 도감 → 전설과 만난 순간**에서 다시 볼 수 있습니다. 최근 탐험 수첩은 최대 40여 건이며 발견 도감/전설 기록은 별도로 유지합니다.

## 한국 날짜의 출석과 미션

한국 시간 오전 0시에 새 날짜가 됩니다. `dailyResetHourKst`로 변경할 수 있습니다. 출석은 버튼을 눌러 하루 한 번 30코인을 받고, 지나간 날은 소급 지급하지 않습니다. 미션은 음식 3회·쓰다듬기 2회·놀이 1회·탐험 완료 1회이며 완료 후 선택한 친구에게 경험치를 수령합니다. 중복 수령은 차단합니다. 첫 탐험·Lv.5·도감 3종 업적도 각각 한 번 수령할 수 있습니다.

## 저장과 백업

검사한 기존 main에는 IndexedDB 구현이 없고 `pocket-friends-v1`이라는 localStorage 키를 사용했습니다. 이 키를 보존하면서 저장 버전 2로 마이그레이션하고, 새 IndexedDB `pocket-friends-stage-two`의 `saves` 저장소에 같은 스냅샷을 저장합니다. 다른 IndexedDB 데이터베이스를 삭제하거나 초기화하지 않습니다.

- 시작 시 두 저장소에서 유효한 데이터 중 저장 시각이 최신인 것을 선택합니다. 둘 다 같은 시각이면 localStorage를 우선합니다.
- v1을 처음 읽으면 가능한 저장소에 `before-v2` 백업을 보관합니다. 사진·이름·상태·좌표·친밀도·기존 대사 타이밍/교감 쿨타임을 읽고 새 필드만 기본값으로 채웁니다.
- 기존처럼 5초마다, 돌봄·구매·사용·미션·귀환 등 변경 직후 저장합니다. localStorage는 즉시 기록하고 IndexedDB는 순서대로 원자적인 스냅샷을 기록합니다.
- 한 저장소가 막혀도 다른 저장소를 사용할 수 있으며 일부 실패는 경고합니다. 모든 원본이 손상되었다면 자동 덮어쓰기를 멈추고 원본을 보존합니다.
- 아래 **추억 보관**은 현재 게임 JSON을 다운로드합니다. **추억 불러오기**에서 JSON 선택 → 확인 내용을 보고 **현재 게임 백업 후 복원**을 누르면 검증 후 교체합니다. 복원 직전 게임도 `before-restore` 백업으로 별도 보관합니다.
- 사진은 이 기기에만 보관하며 서버로 전송하지 않습니다. 계정 동기화는 없지만 백업 파일로 다른 기기에 옮길 수 있습니다. 시크릿 모드 종료나 사이트 데이터 삭제는 브라우저 저장소를 지울 수 있으므로 파일 백업을 권장합니다.

## 설정과 구조

- `src/progression/config.ts`: 레벨 곡선, 보상/쿨타임, 성격 보너스, 출석 초기화, 등급 확률, 아이템/지역/미션 목록
- `src/progression/model.ts`: 순수 게임 동작과 경제·탐험·수집·일일 상태 전이
- `src/progression/migrate.ts`: v1/v2 필드 검사, 기본값, 저장 마이그레이션
- `src/progression/Menu.tsx`, `styles.css`: 기존 디자인에 맞춘 카드 메뉴와 전설 알림
- `src/storage.ts`: IndexedDB/localStorage 복원·백업·저장 순서

## 배포하기

1. GitHub 저장소의 **Pull requests → New pull request**에서 base **main**, compare **feat/stage-two-progression**을 선택하고 **Create pull request**를 누릅니다.
2. 테스트가 초록색으로 통과하면 **Merge pull request → Confirm merge**를 누릅니다.
3. **Actions → Test and deploy Pocket Friends**에서 빌드·테스트·배포 완료를 확인합니다.
4. **Settings → Pages → Visit site**를 누릅니다. 기존 게임 주소를 그대로 사용합니다.
5. Pages가 처음인 경우에만 **Settings → Pages → Source → GitHub Actions**를 선택하세요.

수동으로 실제 서비스를 병합/배포하지는 않습니다. 실제 iOS Safari·물리 펜 기기, 계정 동기화, 장식품의 실제 방 배치는 이 작업의 검증/구현 범위에 포함하지 않습니다.
