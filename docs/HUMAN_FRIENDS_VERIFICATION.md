## 직접 검증한 동작

- 기존 일반 친구 8명, 사진, 코인, 재고, XP, 진행 중 탐험 결과를 보존하면서 두 친구를 덧붙입니다.
- 무료 지급을 반복하거나 두 기기에서 동시에 요청해도 각 ID는 한 명입니다. 지급에 코인/유료 입양 한도를 사용하지 않습니다.
- 먼저 특별 친구를 받은 뒤 일반 친구 4종을 입양하는 순서도 전체 10명을 유지합니다. 유료 입양 기록은 4종만 남습니다.
- 두 투명 PNG는 실제 브라우저에서 디코딩하고 캔버스로 읽었습니다. 완전 투명/불투명 픽셀이 모두 존재하며 이미지 바깥 테두리에 잘린 불투명 픽셀이 없는지 검사합니다. 둘 다 1254×1254입니다.
- PC·모바일에서 두 이미지가 올바른 ID에 연결되고, 실제로 방을 이동하며 한국어 말풍선을 냅니다.
- 짧은 터치/긴 교감/드래그/놀이/휴식/대화/레벨업/야간 수면의 상태 선택을 확인합니다. 교감 중 하트와 행복 상태가 나타납니다.
- 크기 검사는 기존 교감 애니메이션의 의도된 1~몇 % 확대 효과와 구분하여 **레이아웃 컨테이너의 너비·높이**를 비교합니다. 이미지 교체로 인한 프레임 크기 변화는 없습니다.
- 모바일 네이티브 터치 드래그, 이름 변경, 새로고침 후 중복 없음, 원본 로컬 백업을 확인합니다.
- 클라우드에서는 두 기기에 같은 에셋이 표시되고, 개명·개별 친밀도가 공유되며 이전 형식의 쓰기가 거절되는지 확인합니다.
- 사진 캐릭터, 기존 동물 교감·이동·상점·가구·약·탐험·저장/복원 검사를 유지했습니다. 친구 수 검사의 기대값은 특별 지급 2명을 포함하도록 수정했습니다.

## 실제 에셋과 대체 동작

독립 에셋은 남자아이·여자아이의 앉아 웃는 투명 PNG **두 장**입니다. 원본에 없는 정확한 정면/측면/후면, 보행 연속 프레임, 놀란/졸린 얼굴, 누운 수면 원화는 추출하지 못했습니다. 이미지 편집으로 겹친 윤곽을 보완했고, 동작별 CSS 움직임과 하트·느낌표·담요·zzz로 대체합니다. 얼굴을 게임 도중 변형하거나 없는 방향 이미지를 추출했다고 표시하지 않습니다.

## 운영 적용 범위

기존 운영 Supabase 데이터는 직접 읽거나 바꾸지 않았고 운영 배포도 수행하지 않았습니다. 브랜치의 서버와 화면을 배포한 뒤 기존 월드에서 실제 PC·모바일 확인이 필요합니다. 모바일 자동 검사는 Chromium 터치 에뮬레이션이며 실제 iOS Safari/Android 하드웨어 검증은 별도입니다.

[초보자용 배포 클릭 순서](HUMAN_FRIENDS.md). 기존 프로젝트와 Pages 설정을 유지하며 이번 기능에 새 SQL/키는 필요하지 않습니다.
