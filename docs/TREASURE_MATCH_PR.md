## 변경 내용

포켓프렌즈에 독립 로컬 싱글플레이 ‘보물 3매치’를 추가합니다. 8×8 보드, 30개 스테이지, 관통·폭발·무지개·번개 보석과 조합, 연쇄 배율, 입체 SVG 보석, 파편·광선·점수 연출, 터치/마우스/키보드, 일시정지·힌트·로컬 최고 기록을 제공합니다. 코인·육성·아이템 보상은 없습니다.

플레이 중 뒤쪽 방과 햄스터의 렌더링을 쉬게 하고 클라우드 스냅샷 전달을 고정합니다. 기존 클라우드 통신과 대기 명령은 계속 진행하며 종료 시 최신 월드를 다시 조회합니다. 사천성·영단어·서버 명령·SQL은 수정하지 않습니다.

## 검증과 배포

기능 검사, 단계별 자동 플레이, 실제 10분 브라우저 측정은 `docs/TREASURE_MATCH_VERIFICATION.md`에 기록했습니다. 사용법과 규칙은 `docs/TREASURE_MATCH.md`, 클릭별 배포 순서는 `docs/TREASURE_MATCH_DEPLOY.md`를 참고하세요. 추가 SQL이나 서버 배포 없이 PR 병합 후 main 웹사이트 자동 배포를 완료하면 됩니다.
