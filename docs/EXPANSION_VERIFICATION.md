## 운영 적용과 미검증 범위

- 사용자가 기존 운영 PC·모바일 연동 성공을 확인했습니다. 이 업데이트를 운영 Supabase에 설치하거나 기존 월드를 직접 읽고 바꾸지는 않았습니다.
- 운영 계정에서 새 백업 SQL 실행 → PR 병합 → 수동 서버 배포 → Pages 성공 확인이 남아 있습니다. [클릭 순서](LIFE_EXPANSION.md)를 따릅니다. 기존 비밀번호와 프로젝트를 그대로 사용합니다.
- 브라우저 연동 검사는 가짜 네트워크 응답만으로 UI를 속이는 검사가 아니라 동일한 서버 핸들러와 두 기기의 실제 브라우저 요청/응답·인증·실패 재시도를 연결합니다. 실제 Supabase 서비스·운영 데이터에 대한 종단 검증은 배포 후 필요합니다.
- 모바일 자동 검증은 Chromium 터치 에뮬레이션입니다. 실제 iOS Safari와 Android 기기에서의 최종 조작 확인은 별도입니다.
- 사진 자동 배경 제거, 날씨 API, 외형 진화, 개인별 계정 월드는 이 요청의 구현 대상에 포함하지 않았습니다. 사진 원본 얼굴은 계속 유지합니다.
