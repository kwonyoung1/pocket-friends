# 별빛 환수 원본

OpenAI image_gen으로 이번 프로젝트를 위해 제작한 원본 8개 일러스트와 별도 픽셀 아틀라스 8개(캐릭터별 5×4=20포즈, 총160포즈)입니다. 상용 게임에서 추출하지 않았고 필드 도트는 일러스트 축소본이 아닙니다.

네발 여우·토끼·곰·용·늑대·사슴, 두발/두날개 불사조, 다리 없는 두 손의 성운 정령을 구분했습니다. 8장 원화와 160개 런타임 포즈의 접촉 시트를 시각 검토했습니다. 아스트라 픽셀 원본의 회색 배경은 image_gen 편집으로 투명화한 버전을 저장했습니다. 기존 친구 원본은 덮어쓰지 않았습니다.

`node scripts/prepare-beast-art.mjs`는 Sharp로 투명 셀 추출·연결 성분 정리·64px 최근접 정규화·WebP/PNG 압축을 수행합니다. 해부 구조를 그리거나 수정하는 스크립트가 아닙니다. 출처·원본/출력 SHA256·용량은 `src/arena/art/beast-metadata.json`입니다.

실제 모션은 이산 픽셀 포즈와 PixiJS 이동·방향 반전·투사체·전용 타격 효과 조합입니다. 3D 또는 골격 애니메이션으로 보고하지 않습니다. PC 전용 아트나 레이아웃은 추가하지 않았습니다.
