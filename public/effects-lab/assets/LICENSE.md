# Original Effects Lab artwork

All gem-*.svg images in this folder are original mathematical/vector artwork
created for Pocket Friends Effects Lab. They are dedicated to the public domain
under CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/.
No Kenney sprites or third-party animation files are included in these images.
Runtime glow/star/shard textures are generated by the lab's own code.
